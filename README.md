# Howard 的技术笔记

[网站](https://howard-notes.howard-notes-login.workers.dev/howard-notes/) · [文章管理](https://howard-notes.howard-notes-login.workers.dev/howard-notes/admin/) · [静态备用站](https://leiguo0812.github.io/howard-notes/) · [维护说明](docs/webfirst-maintenance.md)

Quartz 5 + Cloudflare Worker / Static Assets / D1 主站，GitHub Pages 作为静态备用站。网页是日常维护入口：公开原文在 Git，私密文章、修改稿、云恢复稿及历史在认证 D1；私密附件在私有 R2。原 Obsidian 库保留不动，旧双向写入已关闭。详见 [网页主维护架构](docs/webfirst-maintenance.md) 与 [备份及恢复](docs/longterm-backup-recovery.md)。

## 原文保存规则

- `library/notes/` 保存原 Markdown 文件；首次迁移逐个校验 SHA-256，连原来的 YAML、注释、空行和 CRLF 换行都保留。
- `library/catalog.json` 保存独立的标题、专题、标签、固定网址、发布日期、创建/修改日期和发布状态。
- `library/site.json` 保存首页布局、专题入口、导航、站点名称和关于页内容，与正文分开同步。
- `library/assets/` 保留既有附件；网页新上传的图片默认保存到独立的 `LeiGuo0812/pic_cloud_gl` 仓库的 `img/` 目录。既有图片链接保持原地址。
- `content/` 是构建时生成的渲染副本，不提交到 Git。双链、锚点等显示适配只作用于此副本，不写回原文。
- `.gitattributes` 为文库关闭换行归一化，防止 Git 悄悄改动源文件。

首次批量迁移包括 172 篇技术与学习笔记。未选笔记、内部资料及本机同步配置不在此仓库；详细迁移清单保存在原 Obsidian 库的“博客发布”目录。

## 网页维护

在主站顶栏点击“登录”，通过 GitHub 官方页面授权后回到原页面与阅读位置。仅博客所有者可以开启维护模式：文章页提供“编辑文章”，顶栏提供新建、草稿箱、文章管理、页面设置、重新登录和退出。文章原位编辑，其他管理功能在主站面板打开；原 `/admin/` 仍可使用，与主站共用编辑器。GitHub 凭据只在维护实例内存中使用，同源加密 HttpOnly Cookie 支持刷新和新标签恢复，授权到期仍需登录；“重新登录”保留未保存的编辑。首次开通见 [账号登录服务](auth-service/README.md)，架构与扩展接口见 [主站维护模式](docs/maintenance-mode.md)。

文章与记忆卡支持云端自动恢复稿和跨设备冲突比较，并保留本机离线恢复补充。显式“存草稿”及私密文章写入认证 D1，公开文章的修改稿独立保存，发布前不影响公开版。私密编辑器可查看版本历史并恢复为新版本；删除后在回收站保留30天。

登录后，主导航的“文章”旁显示“私密文章”。私密栏目有独立列表和完整阅读页，不通过维护弹窗阅读；正文右上角仍可调用共享编辑器。匿名访客只能取得不含笔记数据的页面外壳，列表和原文经维护者 API 读取，不进入公开索引或构建。退出后清空私密阅读内容。

“文章”提供标题、粗斜体、列表、引用、代码、表格、公式、流程图和图片工具栏，以及撤销重做、专注模式、同步滚动。默认并排实时预览 Markdown、KaTeX 公式、Mermaid 和双链；也可切换为纯编辑或纯预览。点击“图片”可多选上传，也可在正文中直接粘贴剪贴板图片。图片先上传私有 R2，插入受鉴权的地址并在本次编辑中预览；发布时单独确认附件公开，随后以固定图床链接映射渲染，保留 Markdown 原字节。新文章默认草稿，网址在首次保存后固定；发布设置不改写原 Markdown。编辑器和正式站点使用不同渲染器，复杂 Obsidian 嵌入以正式站点为准。

“页面设置 → 图片托管”可修改仓库（`账号/仓库名`）、目录和分支，留空目录表示仓库根目录。图片仓库需公开且存在指定分支；仓库授权需包含博客仓库和图片仓库，修改授权后重新登录，不需要粘贴令牌。支持 PNG、JPEG、WebP、GIF、AVIF，单图不超过 10 MiB。上传按内容生成文件名，重复图片复用；公开附件分步提交并保存检查点，不强制覆盖并发提交。外链固定到上传时的提交版本，后续更改图床设置不影响已有链接。取消文章编辑或删除草稿不会删除图床中的图片。

“页面设置”可新增、改名、隐藏、排序专题，调整首页模块顺序与显示状态，选择单栏/双栏、间距与强调色，并修改站点名称、导航文字、页脚和关于页。专题改名只改变显示名称，保留网址和文章归属；含文章的专题需先调整文章归属才能删除。保存设置仅修改 `site.json`，有独立的并发冲突检测，不写入文章原文。

首页“试试手气”在每次进入时随机展示 3 篇公开笔记，使用三栏布局，并保留最近文章和底部热图。专题页纵向展示，每个专题最多预览 4 篇笔记；文章、专题和标签列表每页 20 篇，先搜索/排序再分页，网址保留页码、排序和搜索状态。旧分页网址继续有效。阅读页使用屏幕两侧空间，左边栏靠近屏幕边缘，正文随屏幕扩展至最多 1200px。图谱和目录位于左侧，图谱优先展示引用、共同标签和同专题的笔记标题；手机上可展开目录与图谱。

维护器分别管理公开文章、私密文库、草稿和回收站。修改稿保存在认证 D1，绑定公开 Git 基线；服务端持久任务在关页后继续 Git 提交与 Actions 同步，实际公开投影确认后才显示完成。公开转私密先保留私密原文，再移出当前公开 Git 树及站点投影；旧 Git 历史及公开附件无法收回。

热图统计公开笔记的创建和最近一次修改；同一篇笔记同一天创建和修改只记一次。可查看近一年或具体年份，点击日期查看对应文章。日期按北京时间计算。首次恢复优先使用原文日期属性，缺失时采用原 Obsidian 库最早可查文件/版本记录；不使用网站批量导入日期，不编造创建时间。`created`、`modified` 和 `dateOrigin` 保存于独立目录，原文保持不变，`date` 仍是发布日期。网页修改正文或同步正文变化时更新修改日期，仅调整标题、标签等设置时保留日期。GitHub Actions 每次提交及每日北京时间 00:17 重新构建。

编辑器快捷键：Ctrl / Cmd + B 粗体，I 斜体，K 链接，Z 撤销，Shift + Z 重做，S 存草稿。公开版本仅在点击“发布”后更新。

每次保存会重新读取远端版本，检查原文的 Git blob SHA 和文章设置是否改变。原文和发布目录在同一个 Git 提交中保存，外链图片已在图床独立上传；分支更新始终 `force: false`。发生冲突时保留当前编辑，先下载原文再重新载入。

**这是公开源码与公开原文仓库。** 新的私密草稿和笔记由受鉴权的 D1/R2 保存，不进入这里。曾经提交到本仓库的内容、旧 Git 回收站和历史仍公开可访问，撤下不等于收回历史。

## 本地安装和预览

使用同一套 Linux/WSL 环境中的 Node.js 24+ 和 npm 10.9.2+。

```bash
npm ci
npm run test:publish
npm run build
npm run verify:site
npm run preview
```

预览：`http://localhost:8080/howard-notes/`。`npm run dev` 支持生成目录的预览监听；修改 `library/` 后需重新运行 `npm run export` 生成内容。正式构建总是先生成内容、再构建网站和管理入口。

## 网页维护与本机只读导出

`runtime/config.json` 的 `maintenanceMode: "web-primary"` 会在任何 Git 或网络写入前拒绝旧 `sync --apply`，防止旧本机副本覆盖网页新版本。需要离线阅读时导出到新的受限目录：

```bash
npm run notes:export-private -- \
  --site https://<SITE_HOST>/<SITE_PREFIX>/ \
  --output <NEW_PRIVATE_EXPORT_DIRECTORY>
```

导出包含私密原文、历史、恢复稿和附件元数据，绑定一致的 generation；远端变化时停止，已有目录不覆盖。明文导出与原 Obsidian 库均不上传公开仓库。附件二进制和完整灾难恢复使用加密备份。

初次迁入未上传笔记先运行 `notes:import-private` 的只读预检，再少量试迁、逐字节核验，最后分批迁入，默认全部私密。完整方法见 [迁入及维护约定](docs/webfirst-maintenance.md)。页面设置提供备份状态、手动有界备份与加密包下载；恢复密钥必须另行安全保存。备份需要一致性窗口，回收站和浏览器缓存不替代独立副本。

## 构建与部署

`main` 更新后 GitHub Actions 自动执行：依赖安装、发布与同步测试、TypeScript 检查、网站构建、页面/索引/附件验证和 Pages 部署。失败时保留上一版线上站点。

网站内部链接验证覆盖全部生成页面；源笔记中不完整的本地引用会保留显示文字，记录到本机 `.local/render-report.json`。不批量改写或下载外链图片，也不以迁移为由修订原笔记中的命令或结论。

框架基于 Quartz commit `97a2d05f80c4c50534959b1d0d41cc4b3895625e`，依赖由 `package-lock.json` 固定。上游框架沿用 MIT 许可，见 `LICENSE.txt`。文章及引用资料的来源说明以原笔记为准，未额外授予开放许可。
