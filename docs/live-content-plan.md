# 动态内容与维护体验改造计划

## 目标与边界

保留 Quartz 的视觉、路由、搜索、图谱、双链、公式、代码、图表和维护功能。GitHub `LeiGuo0812/howard-notes` 中的原始 Markdown、目录和页面设置仍是唯一权威来源；迁移不改写原始笔记。图片继续保存在 `pic_cloud_gl/img`。优先使用 Cloudflare 免费套餐，不自动开通付费服务。

## 数据和发布流程

1. 前端代码及资源部署到 Cloudflare Worker Static Assets，保留 `/howard-notes/` 路径；现有 GitHub Pages 保留作为回退。
2. 独立内容 D1 保存当前公开文章、预生成 HTML、搜索索引、页面设置及同步状态。现有登录 D1 独立保留。
3. 编辑、实时预览和恢复草稿在浏览器完成。保存仍先写 GitHub，保留冲突检查和不可覆盖的提交历史。
4. 发布浏览器按现有 Quartz 渲染规则准备公开页面。Worker 检查登录用户、仓库权限、Git 分支当前提交、文章公开状态和原始文件哈希。
5. 分块上传投影，完整性检查通过后一次切换公开版本。访客始终读取完整的旧版本或新版本。
6. 同步错误明确显示“已保存到 GitHub、线上待同步”，重试不再次提交 Git。草稿和草稿删除不更改公开站点。
7. 从本地推送的内容通过同步脚本及 GitHub 内容工作流同步；代码部署与内容发布分开。

## 前端与编辑体验

- 新建文章地址立即可访问；首页、最近文章、专题、标签、列表分页和排序、搜索、关系图谱、反向链接、RSS、站点地图同时更新。
- 公开请求读取已生成页面，避免每次访问执行 Markdown 编译。
- 保留当前玻璃材质、灰色阅读底板、中文排版、主题、移动端折叠侧栏、工具提示、外链新标签页及独立面板。
- 搜索索引按内容版本刷新，正确处理更新和删除；预取仅限用户即将访问的页面，缓存有数量上限。
- 保存请求捕获提交时的内容；请求期间新输入、预览和格式修改继续可用，新输入保留为未保存草稿。
- 保存后使用已提交的精确快照，减少重复读取 GitHub；所有写操作仍检查最新远端基线。
- 已发布、未发布和草稿均保留删除功能；已发布文章暂存草稿不影响公开版本。
- 维护窗口、拖拽、全屏和本地恢复记录不因页面更新而丢失。

## 容量和安全

- D1 保存当前版本及有期限的同步暂存；不保存无限编辑历史，不记录每次阅读。
- 图片不写入 D1。文章源文件只用于公开投影和源哈希验证，原始字节保持不变。
- 登录令牌仅驻留内存；同步服务不保存令牌。同步接口只允许既定维护者，公开接口不返回未发布内容。
- 为数据库查询建立必要索引；提供用量查看、同步版本和状态诊断。
- 超时、并发更新、部分上传和过期暂存均不会切换到不完整或旧的公开版本。

## 验收与上线

1. 通过原有发布测试、TypeScript 检查、构建和站点校验。
2. 增加同步鉴权、公开过滤、哈希校验、分块完整性、原子切换、旧提交拒绝、失败重试和临时数据清理测试。
3. 浏览器验证 390、768、1440px 和两种主题；检查首页、列表、长文、搜索及维护窗口。
4. 以模拟 Git 写入验证新建/发布/草稿/删除/设置、慢网输入保留、失败恢复，不删除用户真实文章。
5. 实际部署 Cloudflare 并导入当前已公开内容；检查 API、文章数量、源哈希、资源和路由。
6. 验证内容同步不依赖全站构建，公开页面、搜索、图谱和列表一致；记录实际执行的测试及未执行项目。
7. 新站稳定后保留旧站回退入口，说明新旧网址与日后内容、代码发布方式。

## 后续扩展接口

独立内容服务、共享投影模块、共享页面渲染器、发布同步控制器和版本化公开 API。后续评论、照片、其他编辑器可使用独立模块扩展，不耦合当前登录数据库或改写 Markdown。
