# Liquid Glass 前端

沿用 Quartz 5、Preact、TypeScript 和 SCSS，玻璃材质本身不引入额外运行依赖。笔记原文、文章路由、搜索索引和分页保留；当前登录、私密存储与发布边界见 [网页主维护模式](webfirst-maintenance.md)。

## 实现

- `quartz/styles/_liquid-glass.scss` 定义浅色、深色材质变量及玻璃和控件混入。没有 `backdrop-filter` 时先使用不透明底色，再通过 `@supports` 启用半透明材质。
- `quartz/styles/custom.scss` 统一悬浮导航、推荐卡片、紧凑列表、胶囊标签、热力图、搜索弹层和阅读排版。环境光位于页面边缘，不使用持续动画。正文和图谱不使用模糊。
- 导航的玻璃背板放在伪元素上，避免背景模糊为原生 Quartz 搜索弹层创建新的固定定位容器。导航和搜索边缘通过蒙版渐变表现反光，投影和环境色透出提供悬浮层次；桌面模糊保持 20px，手机保持 12px。
- 原有配色首页边缘采用低亮度青蓝、蓝紫环境色，浅色对应冰蓝和雾白；六个方案保留同一渐变结构，按各自语义色派生柔和环境色。阅读页自动降低环境色强度。推荐卡片有轻微材质差异，最近文章和活动区域采用更低层的底色，减少重复边框。
- 公开阅读正文默认最大宽度为 1040px，采用左右对称轨道，正文中心对齐屏幕中心；居中模板上限为 900px，仍可在后台调整最大宽度。推荐卡片圆角为 20px。
- 小于 1240px 时目录与图谱折叠；小于等于 800px 时采用两行导航，减少模糊层。手机阅读位置按钮置于正文右侧留白中，正文内边距保持对称。
- 管理入口位于顶部导航，保留原有账号权限。后台即时预览中的导航重排也保持管理入口在末位。
- 后台独立选择中文和英文字体，提供 30 个中文、49 个英文本机字体选项，按字体类别分组。选择的英文家族优先、中文家族随后、通用字体最后；缺少本机字体时自动回退，不下载额外字体。旧版单一 `font` 设置自动映射，保存、草稿、重置和页面预览使用同一套变量与白名单校验。
- 目录锚点使用响应式顶部滚动留白。交互过渡为 180ms，支持 `prefers-reduced-motion`。
- 共享控件的 `control` 混入保留细边框、焦点反馈和过渡，移除顶部额外的白色 inset 内线，避免填色与边框看似分离。“换一组文章”和维护栏的强调按钮 hover 时背景与边框同步换色，不移除面板的玻璃高光或柔光。
- 公开、私密文章列表与记忆卡共用 `nav.site-pagination`、`scripts/lib/pagination.mjs` 和分页样式；私密列表通过 `createPagination()` / `mountPagination()` 接入，每页 20 篇，支持上一/下一页、数字页码和跳转。私密范围的宽泛字体、焦点规则不得覆盖共享分页样式。
- 移动目录展开不再触发缺少路由的全局重绘事件，避免原有图谱错误和控件重复初始化。

## 网站配色方案

登录后进入“页面设置 → 模板与样式 → 配色方案”，可选择“原有配色”以及现代专业、活力可靠、极简柔和、简洁多彩、亲和舒适、清新简约六组浅深色配对方案。“温和稳重”不在目录中。切换方案会同步两种模式的默认链接强调色，保留字体、模板、内容宽度、间距和圆角；浅深色强调色输入仍可单独调整。实时预览包含背景，发布设置后才更新公共网站。顶部主题按钮继续选择浅色或深色，不改变所选方案。

| 方案 / `design.palette`          | 浅色页面底色 | 主要指定颜色与用途                                             |
| -------------------------------- | ------------ | -------------------------------------------------------------- |
| 原有配色 / `current`             | 保留既有值   | 保留既有环境光及正文独立底板                                   |
| 现代专业 / `modern-professional` | `#f3f5f8`    | 商务蓝链接、明黄品牌细节，深色为石墨与冰蓝                     |
| 活力可靠 / `lively-reliable`     | `#eaf0f6`    | 冷蓝基底与赤陶橙按钮，环境渐变采用柔和冷蓝                     |
| 极简柔和 / `minimal-soft`        | `#f9f2e7`    | 卡片/正文 `#f7f8f8`，按钮填充 `#e99f72`                        |
| 简洁多彩 / `clean-multicolor`    | `#f5fafe`    | 独立粉彩 `#ffdce1`、`#fcefd4`、`#c4f2e8`、`#f0d9f8`、`#cbe2f8` |
| 亲和舒适 / `friendly-comfort`    | `#dde9e3`    | 底板 `#fefaf4`、按钮 `#03856f`、正文 `#212529`                 |
| 清新简约 / `fresh-minimal`       | `#efeae1`    | 边线/标记 `#b9b2a1`、正文 `#1c1b19`、按钮 `#b0bcbb`            |

新方案的语义色值与各部位用途严格对应已确认的示例，不能只把全部组件染成同一种强调色。页面背景以 `page` 为基底，并叠加主题派生的低强度边缘渐变；链接使用示例的 `accent`，主按钮使用 `signal` / `onSignal`，品牌细节使用 `mark`（缺省为 `signal`）。这些值彼此独立，不按按钮色临时生成近似链接色。每套方案有自己的深色值，PDF/PNG 仍使用独立浅色导出排版。

| 页面部位                       | 颜色来源与配方                                                                                                          |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| 页面背景 / 公开阅读外围        | `page` 基底与静态边缘径向渐变；阅读外围降低环境色强度                                                                   |
| 导航、搜索、目录与共享玻璃面板 | 导航/普通玻璃底板 `surface` 浅色 64% / 深色 54%；目录磨砂 55% / 62%，边缘用柔和高光                                     |
| 普通推荐卡片                   | `surface` 磨砂底板浅色 55% / 深色 62%，与自身环境色、静态高光和柔光分层                                                 |
| 简洁多彩推荐卡 / 专题卡 / 标签 | 各自 `categories.bg` / `categories.fg`；卡片底板浅色 55% / 深色 62%，标签仍用指定色                                     |
| 正文底板 / 代码块              | 分别为 `reader` / `code` 实色                                                                                           |
| 正文、文章标题、列表标题       | `text`；首页站点标题使用 `display`，缺省为 `accent`                                                                     |
| 日期、摘要、面包屑与辅助文字   | `muted`，不额外降低文字透明度                                                                                           |
| 链接 / 普通胶囊 / 选中态       | `accent`；普通胶囊底色为 `accent` 7% + `surface`，选中为 10% + `surface`                                                |
| 换一组 / 新建等主按钮          | `signal` / `onSignal`                                                                                                   |
| 目录 / 图谱                    | 普通文字 `muted`；选中目录 `accent` + `signal` 左线；图谱主节点 `accent`，次节点 55% `accent` + `surface`，标签 `muted` |
| 引用 / 表格                    | 引用底色 5% `accent` + `reader`；表头底色 3% `accent` + `reader`、文字 `muted`，边线 20% `muted`                        |
| 活动热图                       | 五档为 `signal` 7% / 18% / 34% / 50% / 82% + `page`                                                                     |

所有方案恢复原有材质的渐变结构和层次：导航/普通玻璃底板浅色 64% / 深色 54%，普通玻璃卡片 78% / 80%，独立磨砂卡片与目录 55% / 62%。渐变只用于环境层与玻璃板的静态高光、染色、反光，文字保持锐利；正文 `reader` 与代码块 `code` 仍为实色。不支持 `backdrop-filter` 时使用对应实色回退。目录里的 HEX 与语义用途保持精确，半透明底板叠加渐变后的实际像素由多层背景合成，不再承诺与纯色示例屏幕取样完全相同。

`styles/frosted-glass.css` 从每组当前浅深语义色派生一组相近色：`--site-material-tint` = 24% `accent` + `surface`，`--site-material-soft` = 12% `accent` + `code`，`--site-material-neutral` = 12% `muted` + `surface`。高光 `--site-material-shine` 浅色为 60% `surface` + 白色，深色为 24% `surface` + `text`。先调和成低饱和色族再添加透明度，避免把明黄品牌与蓝链接、橙按钮与蓝背景等差异较大的主色直接混成大面积渐变。

既有 `--glass-pane-*`、卡片染色与边缘光重新使用这组颜色；磨砂静态高光浅深为 19% / 7%，暗部为 7% / 15%，独立环境层三色透明度浅色 34% / 33% / 29%、深色 29% / 34% / 28%。保留原径向渐变的位置、范围与不重复背景；阅读外围只用约 5%–7% 的环境色。独立后台采用同一主题边缘渐变，主站维护 Shadow DOM 的工作区背景透明，不再叠加整页环境光。`admin/maintenance.css` 用 `:host .workspace-body` 与深色对应选择器保证清除背景的优先级，避免独立后台旧深色规则覆盖；维护宿主仍保留 `paper` 实色，面板自身渐变与追光不受影响。

玻璃边框与顶部内高光使用协调的亮色，避免两条偏暗线制造卡片顶部断层。各环境层与底板必须重合并按自身圆角裁切；记忆卡原有 2px 悬停上移作用于包含环境层的整个外壳，防止单独移动内底板露出缝隙。位移、动效时长与指针算法不变。

代码块的 Shiki 内层背景透明，避免遮住 `code` 底板；现有 `runtime/token-classifier.ts` 的分类标签将注释映射为 `muted`、字符串映射为 `accent`，其余语法高亮保留。编辑器原文 `#body` 和预览 `#preview` 均采用 `reader`，预览代码内层同样透明。

`scripts/lib/site-palettes.mjs` 的不可变目录是唯一颜色来源；`site-design.mjs` 校验 `design.palette` 并生成成对 `--site-palette-*-light/dark` 变量。`DEFAULT_DESIGN.palette` 为 `current`，旧设置缺少该字段时保持原色；这不是对当前线上方案的声明。线上由维护者已发布的公开设置决定，部署须读取并保留生产选择，不能以静态 `site.json` 的兼容基线覆盖它。静态 Quartz 和动态渲染器均在 HTML 根写入设计变量及 `data-site-palette`；SPA/实时预览统一更新，切走方案时移除旧方案变量。维护 Shadow DOM 同步根属性与变量，独立后台和设置预览使用同一目录。

共享磨砂 CSS 将颜色与底板配方映射到既有 `--glass-*`、`--frost-*` 和控件 token。目录基色和语义用途固定，材质渐变按上面的同色族配方生成；模糊、阴影深度、圆角、间距、动效时长和鼠标坐标规则不随配色改变。`paletteCategory()` 根据规范化专题身份稳定映射到 1–7 色槽，推荐卡、专题卡及文章标签共用身份钩子，随机推荐、列表排序和内部导航不会让同一专题换色；只有简洁多彩使用这些卡片/标签色槽。设置仍由现有公开 Git/D1 发布流程保存，不新增存储服务或依赖。

品牌和浏览器图标使用扁平纯色板与清晰单色字形，不使用渐变、反光边、纹理、投影或文字发光。`site-brand-colors.mjs` 共用当前浅深方案的 `mark`（缺省为 `signal`）底色及可读前景；`brandIconSvg(settings, { mode })` / `brandIconDataLink()` 生成对应模式的 SVG。四套方案的品牌标记色在浅深模式中相同属于示例设定，不应为追求变化而任意换色。

`admin/brand-favicon.mjs` 的 `mountThemeFavicon()` 观察文档根 `saved-theme`、`style`、`data-site-palette`、`data-site-brand-name` / `data-site-brand-mark`，同步一个持久 SVG data URI 图标。静态/动态公共页面、SPA 与独立后台均挂载，浅深切换和配色预览即时更新且不请求网络。`applyDesignVariables()` 与 `syncSitePalette()` 同步品牌属性，设置预览使用 iframe 自己的文档根；导航品牌也由同一浅深变量更新。清理时断开观察器，内部导航复用图标链接，不重复创建。

静态 PNG / ICO / Apple 图标仍由图标构建器按构建时已保存方案的浅色生成，并以内容 hash 更新缓存链接，作为兼容回退。旧浏览器与已添加到主屏的快捷图标可能要等下次构建及设备缓存刷新，不能保证与 SVG 标签页图标一样即时变化。

## 原有配色的阅读底板与作用范围

下面的固定数值属于“原有配色”。选择新方案时，同一阅读 token 改用该方案的值，局部作用范围保持不变。阅读底板保持清晰、接近不透明，不通过增加背景模糊或文字透明度调亮。公开与私密正文共用独立 token；原有配色的共享面板保留原色：

| Token                    | 浅色      | 深色      | 作用范围                                                       |
| ------------------------ | --------- | --------- | -------------------------------------------------------------- |
| `--glass-reader-surface` | `#fafbfc` | `#343b45` | 公开 `#main-content` 与私密 `.private-reading-body` 的正文底板 |
| `--glass-reader-page`    | `#f3f5f7` | `#242a33` | 仅 `body:has(.blog-layout.is-article)` 的公开阅读外围          |
| 全局 `--glass-reading`   | `#eef0f2` | `#252a31` | 搜索、热图、图谱、维护面板及其余共享底板                       |

`quartz/styles/_liquid-glass.scss` 管理主题值；`custom.scss` 中 `.blog-layout.is-article > #main-content` 和 `_private-notes.scss` 中 `#private-notes-app .private-reading-body` 只在各自正文范围内把 `--glass-reading` 覆盖为 `--glass-reader-surface`。正文中的表格底色随其协调，旁边目录、首页及其他模块不继承此覆盖。私密外壳没有套用公开外围背景规则，不应把全局 `--glass-reading` 改成正文新颜色。

原有配色的正文前景浅色 `#354154`、深色 `#c7d0dc`，与对应底板的计算对比度约为 9.96:1 与 7.26:1。所选新方案的前景与底板以目录为准；这些数值不是全站无障碍认证，也不代替浏览器验证。

## 视觉回归流程

检查首页、文章列表、公开/私密阅读、搜索和管理页面，在 390、768、1440px 及浅深两色中验证。长标题、链接、代码和表格用合成内容检查溢出，代码/表格只在自身区域横向滚动；不要为清除渲染警告改写原文。

检查导航悬浮、独立面板间隙、目录滚动、手机抽屉、随机卡片、主题、锚点、图谱、阅读位置按钮、字体回退和维护预览。强调按钮静止和 hover 均无额外顶部白色内线，填色与边框同步，键盘焦点仍清楚。公开/私密分页检查数字、首尾边界、跳转、单页隐藏、筛选归页、列表回顶及卸载清理，当前页使用 `signal` / `onSignal`，不被私密局部字体或焦点规则覆盖。触屏、减少动态效果与无 backdrop-filter 场景需要单独检查。字体菜单不代表设备已安装对应字体，未安装时应明确回退。

逐项切换原有配色与六个方案，核对首页/正文/搜索/独立后台/维护浮窗/设置预览一致；检查浅深两色、旧设置默认、回到原色及切走多彩无残留。逐项检查实际组件的 `text` / `muted` / `accent` / `signal` / `reader` / `code`、玻璃 alpha 与多彩类别底色，不以变量存在代替正确使用。检查静止渐变柔和、阅读页装饰减弱、顶部高光无暗线断层、面板与环境层边界重合、记忆卡上移不露缝。对照修改前的模糊、阴影、尺寸、hover 与追光时序，确保材质恢复没有改变交互。检查扁平品牌与 SVG 标签图标在主题切换、配色预览、SPA 和后台中即时同步，以及静态回退图标的 hash 更新；发布后分别确认 Git 设置和动态公开 revision，不以本机预览代替上线结果。

运行现有类型、格式、发布测试、构建和站点检查；浏览器测试与实体设备测试分别说明，不保留旧轮次验收流水。
