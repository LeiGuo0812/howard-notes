# 主站维护模式

主站与 `/admin/` 共用 `admin/workspace.mjs`，不从已渲染 HTML 还原笔记。`admin/personal-library.mjs` 合并公开 Git 文库与认证 D1 私密文库供维护者操作：公开原文和页面设置以 Git 为准，私密原文、修改稿、恢复稿和历史以认证 D1 为准，私密附件保存在私有 R2。公开投影只接收明确发布的内容，不能把维护者的合并目录送入搜索、页面设置预览或公开同步。

本文的使用与安全约定按当前网页主维护架构说明；完整存储和发布边界见 [网页主维护模式](webfirst-maintenance.md)。验证按当前流程执行，不累积历史结果。

## 使用路径

- 主站顶栏登录 → GitHub 授权 → 返回原地址、查询参数、锚点和阅读位置。
- 阅读文章 → 编辑文章 → Markdown 格式工具及本机实时预览 → 存草稿或发布。
- 新建、草稿箱、文章管理、页面设置在主站面板打开，支持收起后继续阅读。
- 顶栏「已登录」仅显示登录状态；首页使用图标加文字的维护按钮，阅读页的维护工具位于右侧，文章右上角的编辑图标打开原位编辑器。
- 维护面板支持全屏与还原；桌面可拖动标题栏调整浮窗位置。窗口操作与文章缓冲区分开，移动端使用可触达的全屏控件。
- 手机默认编辑视图，可切换预览；桌面并排编辑与预览。
- 文章正文的双链和外链在新标签页打开；导航栏、文章列表和目录保持原浏览方式。
- 已发布文章的修改草稿独立保存到认证 D1，公开原文仅在显式发布时更新。发布完成以公开 Git 提交及 D1 投影确认结果为准；Pages 工作流状态单独表示备用静态站的构建状态。
- 已发布文章的编辑器提供「删除文章」；编辑它的修改草稿时提供「删除已发布文章」。公开原文及 Git 中的关联修改稿原子移入 Git 回收站；D1 中的关联修改稿分别按版本移入私密回收站，若其中一步失败则保留稿件并提示，不宣称两种存储能够一起原子删除。「删除草稿」仍只删除当前草稿。
- 未公开或撤下后的私密正式文章提供「删除文章」，私密草稿提供「删除草稿」，均通过认证接口移入 D1 回收站。本机恢复记录也可删除；原远端已不存在时显示「删除本地草稿」，只清理浏览器记录。
- 登录后主导航显示「私密文章」，提供独立列表、按需完整阅读和原位编辑；匿名页面只是无数据外壳，不读取私密目录或原文。

访客只加载轻量启动器。`maintenance.mjs` 只负责会话、权限状态、导航及命令入口；恢复登录不会加载完整目录与编辑器。第一次打开维护窗口时，才动态导入 `maintenance-workspace.mjs`、共享表单和样式。独立后台和主站分别构建入口，但使用同一套 `workspace.mjs` 和同一份 `admin/index.html` 表单。

编辑预览由 `runtime/editor-preview.ts` 在独立 Worker 中复用正式 Quartz 编译器，提示块、代码、公式和净化规则与正式阅读一致。连续输入只保留最新待处理版本，过期响应不得覆盖新文章；图片解析和 Mermaid 生命周期仍由主线程控制，不把原文或登录凭据发送给 Worker 之外的服务。

维护工作区使用 Shadow DOM 隔离样式与 ID；输入锁定仅作用于工作区。Quartz 在 `prenav` 时拆下维护宿主，在 `nav` 时重新挂载同一个宿主，避免 `micromorph` 替换编辑器；会话、撤销历史和未保存缓冲区因此保留。编辑原文章时挂到正文位置，导航到其他页面时以面板继续保留。

## 扩展接口

`createWorkspace(root, options)` 接受站点根 URL、会话变化、重认证、关闭、保存完成等回调。返回文章打开、新建、模式切换、忙碌状态、关闭、退出与销毁等方法。公开会话信息只有账号和时间，不包含令牌。`onSaved({ kind, articleId?, removedIds?, scope?, commit? })` 可用于部署状态和后续版本历史功能；删除回调包括原文和关联草稿的 ID、返回的文章或草稿列表范围。

主站控制器通过命令表分派操作，`registerCommand(name, callback)` 可增加后续维护入口。新的主站按钮使用 `data-maintenance-action`，无须复制编辑器状态或在阅读组件中加入保存逻辑。域服务继续独立在 GitHub、图床、格式、预览和恢复模块中；迁移服务时可保持工作区与主站挂载接口。

维护窗口在普通面板、全屏与文章原位编辑之间移动同一个宿主，不重建编辑器。桌面标题栏支持指针拖动和方向键移动；窗口缩放后重新限制在视口内。小屏右侧工具菜单按 1240px 断点折叠，选择操作后收起，图标同时提供 `title`、无障碍标签及悬停提示。

首页卡片、目录及导航沿用原有玻璃配色，公开及私密正文单独使用 `--glass-reader-surface`（浅色 `#fafbfc`、深色 `#343b45`）。仅 `.blog-layout.is-article > #main-content` 与 `#private-notes-app .private-reading-body` 在自身范围内覆盖 `--glass-reading`；公开阅读页外围通过 `body:has(.blog-layout.is-article)` 使用 `--glass-reader-page`（浅色 `#f3f5f7`、深色 `#242a33`），私密外壳不套用这一外围规则。共享底板、搜索、热图、目录和维护面板继续使用原来的全局 `--glass-reading`（浅色 `#eef0f2`、深色 `#252a31`），避免正文调色影响其他模块。正文、链接及辅助文字保持独立的前景色，不通过整体透明度降低阅读对比。

## 状态与安全边界

浏览器令牌只在当前维护实例内存中，内部导航保留。Cloudflare 主站使用加密的同源 Secure、HttpOnly、SameSite=Strict Cookie 恢复有效会话，刷新或新标签不必重新授权；恢复仍由服务端核验 GitHub 身份与仓库权限，到期或退出后失效。手机初次登录采用同页跳转；正在编辑时重认证采用弹窗保留页面。回跳仅允许同源和本站部署路径，路径、查询参数及锚点保存在加密流程中；令牌不进入 URL、布局预览或本机恢复稿。登录返回有效期继续使用服务器时间，主站会话到期判断使用单调时钟。Pages 备用域名不会共享主站 Cookie，使用独立登录路径。

本机恢复稿保存文章原文、编辑表单、原文章目录项和最初 SHA。恢复时即使远端变化，也不会把旧编辑换成最新基线；现有服务拒绝并发覆盖。恢复存储有数量和大小上限，存储失败时可以下载原稿。输入后短暂合并写入，切后台和离开页面时立即暂存。

本机恢复稿只属于当前设备，可能以明文保存在浏览器中，退出并不自动删除；它不是长期备份。编辑恢复稿也可通过认证 D1 保存以便恢复，云端恢复稿请求按编辑器串行发送、带 UUID 幂等编号与最初基线，冲突后不自动覆盖远端。显式保存的私密文章及修改草稿进入 D1，不默认写入公共 Git。旧公开仓库中已经存在的草稿和历史仍可被仓库访问，不能因为网页隐藏就视为私密。

新的私密图片先上传私有 R2，由认证接口读取为临时 Blob。显式发布含私密附件的文章时，须单独同意附件公开，持久任务才向配置图床复制原文件并生成公开地址映射；没有同意或校验失败时保留私密内容。既有公开图床链接保持公开，不保证因文章撤下而收回。取消编辑不会自动删除共享图床文件或私密 R2 原附件，正文的 BOM、CRLF 和全部原文字节保持原保存规则。

公开删除使用独立的载入版本基线：公开原文及同次 Git 操作中关联稿件的目录项、文件 SHA 必须保持一致。目录变更与原文存档在同一提交完成，分支更新不使用强制覆盖；发生并发更改时保留编辑器和恢复稿。D1 私密文章、修改稿和恢复稿使用各自的版本与 UUID，请求不会因重试重复删除。取消确认不更改内容；确认删除后清理对应的本机恢复记录，列表刷新失败也不把已确认的删除误报为未执行。公开删除已成功而私密关联稿删除失败时，保留失败的稿件并显示具体提示。

删除仅作用于对应的网页维护存储，保留共享图片、页面设置和无关文章，独立 Obsidian 原始笔记不受影响。网页为主维护后，旧双向 `sync --apply` 不再作为正常流程；本机仅作只读导出和独立备份，不用三方同步重新覆盖网页版本。

## 回归检查流程

运行 `npm run test:publish`、`npm run check`、`npm run build:cloudflare`、`npm run verify:site`。检查版本化维护入口、共用表单、登录入口、后台 CSP、公开文章、RSS 和搜索索引。

浏览器使用合成授权及隔离仓库检查桌面与手机布局、明暗主题、导航保留编辑、草稿/发布/冲突、退出清理、图片与图表、浮窗和回收站。真实系统授权及文件分享需另用实体设备验证，模拟通过不代表真实账户流程已经执行。不得用用户原文章测试永久删除。

## 后台发布与登录保持

私密原文、草稿和恢复稿保存到认证 D1，不触发公开同步。显式公开或转私密先确认 D1 固定版本和公开 Git 基线，再登记 `publication_jobs` 持久任务。服务端负责受限 Git 操作、已同意的附件复制、检查点、重试与状态；GitHub Actions 编译公开内容并原子切换 D1 公开投影。服务端核对实际公开提交及原文 SHA 或撤下结果后才标记完成。

页面设置和现有公开 Git 删除先确认 Git 提交，随后登记 `sync-public`；push 工作流继续提供同步保底。浏览器加速路径可以复用模块 Web Worker 编译、渲染、比较、哈希和上传分块，凭据不传给渲染线程，线程空闲一分钟后释放。所有公开加速与同步输入只使用 `publicSnapshot`。

发布期间界面可以拖动、全屏、还原或收起，左下角进度区分已保存、已进入任务、Git 已提交、等待同步和已上线。关闭页面会停止浏览器加速线程，但不会取消服务端已经接收的持久任务，后台可以继续执行并在重新打开后查询状态；短期授权过期时任务等待重新登录恢复。尚未收到服务端确认的操作不能视为已保存或已入队，应保留原稿并幂等重试，不能仅凭关闭前点击了按钮就承诺最终上线。

Cloudflare 主站提供同源 `/api/content/session`。服务端使用 `SESSION_SECRET`
加密会话，并通过 Secure、HttpOnly、SameSite=Strict Cookie 保存。
恢复会话仍核验 GitHub 账号和仓库写入权限，最大有效期受 GitHub 授权限制为八小时。
刷新主站、新标签页和独立管理页面共享该 Cookie；退出时清除 Cookie。
本地缓存只存自动恢复提示的到期时间，不存令牌，不能凭此提示取得权限。
GitHub Pages 备用域名不会跨域读取主站 Cookie，仍沿用原登录流程。
`SESSION_SECRET` 必须通过 Worker secret 配置，不进入代码、D1 或公开资源。

## 居中窗口、即时反馈和回收站

首页打开新建、草稿箱、文章管理、回收站和页面设置时，窗口默认居中。
拖动位置和全屏状态在收起后重新打开时重置。鼠标经过或键盘聚焦维护入口，只预热
轻量会话控制器，不加载完整编辑器和目录。

首次点击页面设置等维护窗口入口，先同步创建带标题、窗口控件和占位内容的轻量
窗口；等待两个动画帧，让浏览器先显示窗口，再导入完整工作区和读取模板。
页面设置首次连接时，身份与仓库写权限验证和必要的公开设置读取并行进行，
全部成功后才启用表单；私密文库目录不再阻塞设置就绪。加载期间仍可拖动、全屏、还原或收起，左下角显示进度和
重新打开入口。就绪后完整工作区承接当前拖动位置和全屏状态，不跳回中心。
收起、导航、退出或会话到期使旧打开意图失效，晚到请求不能自行弹回窗口或恢复
已失效的登录；失败可重试。

`GitHubLibrary.settingsSnapshot()` 先读取当前分支的 commit，再在这个固定版本
并行读取 `library/site.json` 和 `library/catalog.json`，保留准确的设置文件 SHA。
它显式标记 `settingsOnly`，没有完整 Git tree 和文章文件基线，不能冒充完整文库。
内容校验后只按不可变 blob SHA 复用字节，不缓存可变分支；保存设置仍重新取得
完整 Git snapshot、检查设置 SHA 与专题占用，并以非强制提交保护并发写入。

只查看设置时，不主动加载完整文库。首次进入文章维护功能或需要监测、重试发布任务时，
个人文章、草稿和任务元数据才按需在后台分批加载。`PersonalLibrary.ensureSnapshot()`
共享同一实例的在途初始化，失败可重试；`personalReady` 只在完整读取后成立。
文章管理、草稿、私密文章、新建、编辑和回收站依赖该文库，先等待同一准备过程，
不把尚未读取的私密条目当成空文库。补齐数据不会重新载入设置表单或替换工作中的
布局草稿；期间已保存的新公开设置基线也不能被旧初始化结果覆盖。日常刷新仍读取
权威当前版本，不把首开去重变成长期快照缓存。

重复点击共享一次模块加载和连接，最后选择的窗口生效。已连接工作区的再次打开
沿用原实例及编辑缓冲，不重新读取整个目录。`PersonalLibrary.endpoint()` 合并
同一实例并发的运行配置请求；失败后允许重试，不缓存登录凭据或私密正文。后台
补齐时按当前视图更新列表，避免在设置模式重复构建不可见的文章列表。

页面设置作为普通浮窗时，点击窗口外的页面可收起；这不发布、不丢弃布局草稿，
再次打开继续编辑。收起仍保留文章缓冲及版本基线。维护入口、搜索、分享和其他
弹层不会被视作窗口外关闭，拖动或触屏滚动结束也不误收起；点击外部链接仍保留
原有导航行为。加载窗口同样可收起，晚到结果只更新进度，不重新打开面板。

设置预览使用同源独立 iframe 样稿，提供首页、专题、文章列表和阅读页四个场景。
`scripts/build-site-preview.mjs` 将轻量渲染器和样稿 HTML/CSS 构建为哈希资源，
样稿引用与该次主站构建一致的正式 CSS；维护清单通过 `sitePreviewEntry` 绑定
对应 HTML，部署继续保留旧页面需要的递归依赖。浏览器和部署保留工具通过同源无后缀地址读取样稿，清单仍记录并校验原始哈希 HTML 文件，避免 HTML 规范化重定向破坏部署前缀或校验。场景切换只更新同一 iframe，
隐藏时释放为 `about:blank`，再次打开按当前设置绘制。

样稿只接收经过 `sitePreviewSettings()` 白名单投影的品牌、配色、字体和布局字段，
固定使用有界合成文章、记忆卡、热图和正文，不读取真实文章目录或原文，也不发送
图床配置、凭据或私密数据。双方检查消息 origin/source，子页 CSP 禁止内容网络请求。
它用于比较明暗配色、字体、间距、圆角、模块顺序、专题和列表布局；图谱、搜索、
登录、分页、真实活动数量及文章内容不是完整主站复刻。发布后的真实内容和完整
页面交互仍需在主站检查，样稿不能代替文章编辑器预览或正式验收。

发布、保存、撤下、删除、恢复和永久清理通过统一的任务回调立即收起。
屏幕左下角统一显示非阻塞状态、重新打开和同步重试入口；异步写入的冲突检测不变。
私密保存成功无需等待公开投影；公开变更的待同步提醒只有在实际公开版本确认后才清除。

验证首次打开时，用隔离浏览器和合成会话延迟工作区模块、模板或目录请求，分别
检查浅深主题及 390/768/1440px：窗口应先于这些请求完成出现，慢网期间控件可用；
拖动/全屏后就绪保持位置，收起或离页后不弹回，快速切换只显示最后的选择，失败
可以重试。另检查重复打开沿用编辑内容，以及加载期间退出/到期后不恢复权限。
记录“首个可见响应”和“设置可编辑”两个时间，不能将占位窗口出现当成设置已加载
完成，也不能把浏览器模拟当作实体手机验证。

网页统一展示两类服务端回收站，它们保留不同的权限与恢复依据：

- 公开 Git 回收站位于 `library/trash/<UUID>/`，包含 `record.json` 与原文 Git blob 存档；从公开目录移除时原子保存本次 Git 操作涵盖的稿件。恢复保留文件路径、文章标识、元数据、原文字节及发布状态，冲突时拒绝覆盖。存档不进入站点页面、搜索和公开内容 API，但公开仓库中的存档和 Git 历史仍可直接访问，不能用于存储秘密。30 天后不再可恢复，`trash-cleanup.yml` 每天只清理验证完整的过期存档；坏记录和未知文件保留并报告。
- 私密 D1 回收站保存文章、修改稿及云端恢复稿的 `TRASH` 状态和删除时间，仅维护者可读。删除、恢复和永久清理使用当前版本及 UUID；30 天内可恢复，过期后由服务端清理规范记录。恢复私密内容不会自动公开，也不会自动删除私密 R2 原附件。

尚未确认保存到服务端的本机恢复稿还有当前浏览器的独立回收站，30 天到期后在浏览器再次读取时清理；本地存储失败时保留当前编辑，不假称删除成功。它是设备内防误删补充，不是第三种服务端权威文库，也不能代替长期加密备份。任何清理均不重写 Git 历史或修改独立 Obsidian 原始笔记。

连续公开发布只复用精确匹配服务端确认 revision/commit 的内存快照和页面模板。
每次仍先验证 GitHub 和 D1 基线；并发更新或失败使缓存不能冒充已上线内容。

## 手机阅读导航

800px 以下的文章页使用固定右侧「目录 / 图谱」入口，位于到顶、到底按钮上方。
点击展开可滚动抽屉，优先显示目录，其后保留清晰的关系图谱及全局图谱入口。
目录点击先收起抽屉，再沿用站内锚点导航；关闭按钮、点击外部和 Escape 均可收起。
桌面保留左侧栏，内部导航和窗口宽度变化通过现有 SPA 清理机制管理事件。

## 专题卡片、缩略图和时间线

专题卡片在桌面使用两列错位排列，600px 以下改为单列。后台仍可切换原列表布局，
页面预览保留新卡片材质及设置的间距。短页环境背景禁止重复平铺，避免页脚下色块。

文章列表从正文实际解析的第一张图片生成可选缩略图，静态构建和即时发布共用
同一 URL 规则；使用懒加载、异步解码和无引用来源请求，失败时隐藏图片位置。
独立缩略图版本可从已有压缩 AST 补元数据，不改原文或强制重新高亮编译。

文章页、专题和标签内的二级文章列表支持列表与时间线切换。列表仍每页 20 篇；
标题下显示一行摘要，超出部分省略，时间线卡片保留三行摘要。
时间线展示全部筛选结果，按当前创建/更新时间排序分组，标题排序时按创建年月分组。
桌面文章跨月份连续左右交替，手机单侧排列。年月侧栏仅在时间线显示，
按当前筛选结果提供年份和月份跳转；窄屏使用可展开的悬浮入口。
年月跳转沿用页面滚动，`view=timeline` 可与 `q`、`sort`、`activity` 参数组合分享。
浏览器发布直接加载构建时对应的哈希 Worker，避免备用域稳定入口缓存旧渲染器。
