# 磨砂玻璃与鼠标柔光

沿用 Quartz、Preact、TypeScript/JavaScript 和 CSS/SCSS，自行实现材质及 PointerEvent 交互，不增加运行依赖或改动笔记原文。页面设置可选择配色，材质和指针交互继续共用现有实现。

## 材质与交互

推荐卡片的环境层、磨砂底板、柔光和文字分层渲染。hover 保留半透明材质，不使用纯白背景覆盖，也不整卡上移。

- 环境层位于每张推荐卡片独立的圆角容器：原有配色使用固定、低饱和青蓝和蓝紫色块；六个方案按各自 `accent` / `surface` / `code` / `muted` 派生相近色，恢复同一环境渐变结构。不给父容器添加整体 opacity、filter 或 mask。卡片行本身透明，间隙没有共用环境底板。
- 卡片自身使用真正的 `backdrop-filter: blur(24px) saturate(140%)`。所有方案的浅色磨砂底板不透明度 55%，深色 62%；普通方案使用自己的 `surface`，简洁多彩的推荐卡与专题卡使用对应 `categories.bg` 作为基色，静态高光、染色与反光沿用原材质结构。不支持背景模糊时使用实色替代。
- 静态高光、内阴影及 3.5% 的细颗粒构成磨砂表面。文字层位于光层上方；没有给整张卡片或文字设置 filter。
- 柔光由 80px 内层和 230px 外层径向渐变构成，中心由 `--mouse-x`、`--mouse-y` 即时更新，边缘有独立的 1px 蒙版反光。移入 150ms、移出 250ms，仅透明度过渡，没有坐标拖尾、纯白 hover 或卡片上移。
- 委托监听涵盖新随机推荐和标题、摘要、标签。WeakMap 防重复挂载，Quartz 页面清理时移除监听；离开、失焦、滚动、页面隐藏和媒体偏好变化时清除追光。
- 触屏保留静态磨砂，将模糊降至 16px；减少动态效果时关闭追光并保留底板。

阅读页的目录面板使用相同材质与局部柔光，正文与图谱文字保持稳定清晰。图谱与目录分别拥有独立底板；侧栏、折叠容器与面板布局容器均透明，不使用共享玻璃背板。窄屏折叠入口是独立控件，目录自身保留磨砂，没有祖先嵌套模糊，图谱弹层保持相对于视口定位。修正了前缀声明顺序，保证打包后标准 `backdrop-filter: none` 不会被丢弃。

后台导航、登录、文章侧栏和页面预览面板采用同一材质；登录和辅助面板有局部追光，编辑文本和正文预览保持实色。新增主题按钮，与公开页面共享主题存储及系统偏好。

## 修改文件

- `styles/frosted-glass.css`：公开页面和后台共用的材质、静态颗粒、双层柔光与边缘高亮。
- `scripts/lib/frosted-spotlight.mjs`、`.d.mts`：委托监听及清理。
- `quartz/styles/custom.scss`：移除背景覆盖，提供环境层和响应式阅读样式。
- `quartz/components/Blog.tsx`、`quartz/components/scripts/note-browser.inline.ts`：初始推荐、新推荐及目录接入。
- `admin/admin.css`、`admin/index.html`、`admin/app.mjs`、`admin/theme.mjs`、`scripts/build-admin.mjs`：后台材质、主题、共享样式发布。

## 独立面板、浅色柔光、目录与图标

推荐卡片与目录各有自己的 `.frost-environment` 圆角环境层；布局容器透明，仅负责间距。环境层与卡片底板范围重合，高光与边框协调，避免顶部出现双暗线断层。记忆卡原有 2px 悬停上移改为移动整个外壳，使环境与内底板同步，不改变位移或时序。局部阴影不跨越间隙，初始 HTML 与随机刷新卡片采用相同结构。图谱与目录不共用覆盖整条侧栏的背板，手机抽屉也不能叠加祖先模糊导致弹层定位失效。

原有配色的浅色追光使用冰蓝：内层 `rgb(166 216 245 / 22%)`、外层 `rgb(159 215 242 / 9%)`、边缘 `rgb(119 184 222 / 50%)`；深色单独控制。新方案按各自按钮色生成柔光色，沿用浅色 22%/9%/50%、深色 20%/13%/82% 的强度及原有半径、时序。公开页面、目录和后台共用变量。

目录内层 `ul.toc-content.overflow` 保持可见溢出并允许滚动传播，不使用渐隐蒙版或 JavaScript 滚轮拦截。外层 `.reading-tools` 负责桌面滚动，鼠标位于图谱、间隙、标题、链接、列表空白、内边距或滚动条旁均应可滚动；折叠列表使用 `display:none`。

品牌图标为扁平纯色圆角板和单色字形，不使用渐变、反光边、纹理、投影或发光。新方案按当前浅深模式使用 `mark`（缺省为 `signal`）作为底色，原有配色回退到对应强调色；共享 `site-brand-colors.mjs` 按底色计算可读前景。`brandIconSvg(settings, { mode })` / `brandIconDataLink()` 生成当前模式的扁平 SVG。四套方案的浅深标记色相同属于示例设定，切换配色时仍使用新方案色值。

公共页面、SPA 和独立后台通过 `admin/brand-favicon.mjs` 的 `mountThemeFavicon()` 观察文档根主题、颜色及品牌属性，更新一个持久 SVG data URI 图标；换浅深色或实时配色预览立即同步，无网络请求。`applyDesignVariables()` / `syncSitePalette()` 同步品牌属性，预览使用 iframe 自己的文档根。导航标记由同一配色变量同步；页面清理时断开观察器，内部导航不重复创建图标链接。

图标构建器仍按构建时已保存方案的浅色生成 SVG、32/180/512px PNG 和 16/32/48px 多尺寸 ICO。公开页、404、后台保留内容 hash 的静态兼容资源链接，以及兼容 PNG、根目录 ICO 和 Apple 图标；更新这些回退文件需重新构建。旧浏览器与主屏快捷图标受设备缓存影响，不保证即时随主题变化。

## 视觉回归流程

浅深两色检查静止磨砂、左上/中心/右下追光、离开淡出、文字锐利、点击穿透、换组及内部导航。按卡片局部坐标对照截图，不能只检查 blur 声明。检查面板顶部无暗线断层、环境层与底板重合、记忆卡悬停不露缝、面板间隙无共享色块、监听不重复、触屏静态 16px 材质、减少动态效果关闭追光、无 backdrop-filter 的实色回退。

在 390/768/1440px 检查首页、阅读、列表、搜索和管理页；长目录在整个侧栏范围检查上下滚轮及末尾可达，正文仍独立滚动。核对 SVG 图标在浅深切换、配色预览、SPA 和独立后台中即时同步，另检查静态回退资源的引用、响应、解码和缓存更新；实体手机和 Safari 未执行时必须说明。

## 当前正文配色与材质隔离

登录后“页面设置 → 模板与样式 → 配色方案”提供原有配色及六个浅深色配对方案，完整色值和架构见 [Liquid Glass 前端](liquid-glass-frontend.md#网站配色方案)。目录 `scripts/lib/site-palettes.mjs` 生成 `--site-palette-*`，共享 CSS 将示例颜色及底板配方映射到现有材质变量；维护浮窗的 Shadow DOM 同步根变量与 `data-site-palette`。所有方案使用原材质透明度与渐变结构，新方案按自己基色生成低饱和环境色；blur、阴影层次、尺寸、hover 位移与时序、双层柔光的指针跟随和事件清理保持原实现。

以下固定数值属于原有配色；新方案使用自己的正文/外围颜色。公开与私密正文使用 `--glass-reader-surface`：原有配色浅色 `#fafbfc`、深色 `#343b45`。仅 `.blog-layout.is-article > #main-content` 和 `#private-notes-app .private-reading-body` 在自身范围内将 `--glass-reading` 覆盖为该阅读 token；正文、代码、表格与图表保持清晰，不给阅读内容加入磨砂或持续追光。

公开阅读外围的 `--glass-reader-page` 为浅色 `#f3f5f7`、深色 `#242a33`，只作用于 `body:has(.blog-layout.is-article)`。私密外壳不套用此规则。全局 `--glass-reading` 仍为浅色 `#eef0f2`、深色 `#252a31`；首页、目录、搜索、热图和维护等模块保留原共享配色。不能为了调亮正文而改共享 token，或让相邻独立面板继承正文覆盖。

新方案页面以 `page` 为基底恢复静态边缘径向渐变，独立卡片与目录恢复环境层及底板高光/染色/反光。共享 CSS 派生相近色：24% `accent` + `surface`、12% `accent` + `code`、12% `muted` + `surface`；高光浅色为 60% `surface` + 白色，深色为 24% `surface` + `text`。不把差异很大的品牌色与按钮色直接混成大面积背景。导航底板不透明度浅深为 64% / 54%，普通玻璃卡片 78% / 80%，磨砂卡片与目录 55% / 62%；多彩卡片仍使用自己的类别 HEX 作半透明基色，标签保持指定类别色。浅深磨砂高光为 19% / 7%，暗部为 7% / 15%，环境层三色透明度为 34% / 33% / 29% 与 29% / 34% / 28%。保留原径向渐变几何，阅读外围环境色降至约 5%–7%，正文和代码块仍为实色；独立后台有同样的边缘渐变，维护工作区背景保持透明。`admin/maintenance.css` 用 `:host .workspace-body` 与深色选择器压过独立后台背景规则，宿主保留 `paper` 实色，面板渐变与追光继续生效。

目录中的基色和用途精确，合成像素随渐变与半透明层变化，不承诺与纯色示例屏幕取样相同。

玻璃边缘反光、内阴影、颗粒与鼠标柔光保留。正文标题使用 `text`，首页标题使用 `display`（缺省 `accent`）；日期、摘要、普通导航和目录使用 `muted`，链接使用 `accent`，换组与新建等主按钮使用 `signal` / `onSignal`。胶囊、选中态、引用、表头与热图使用示例中各自的颜色混合配方，完整映射见配色文档，不混用强调色。Shiki 内层背景透明，保留 `code` 底板；使用现有 tokenClassifier 标签把代码注释映射为 `muted`、字符串映射为 `accent`，其余语法高亮保留。编辑原文 `#body` 与预览 `#preview` 均使用 `reader`，预览代码内层透明。原有配色继续保留既有页面环境光。多彩色槽按专题身份稳定分配，推荐卡、专题卡与文章标签共用身份钩子，不随推荐换组或排序改变；切走多彩时清除旧色槽变量。

旧配置缺省仍是 `current`；当前线上配色以维护者已发布的公开设置为准。部署保留生产选择，不用静态配置中的缺省值重置线上方案。

材质与柔光继续使用 `--frost-*`、`--mouse-x`、`--mouse-y` 等既有变量和清理逻辑，底板与环境层按方案的同色族配方生成渐变，不重调模糊、半径、时序或指针层级。视觉回归还需检查旧设置仍默认原色、六组方案浅深模式和维护/预览一致，以及各实际组件的颜色用途、扁平图标和追光 / hover；完整当前视觉约定见 [Liquid Glass 前端](liquid-glass-frontend.md)。

## 参考
