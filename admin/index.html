首次使用：如何获取登录令牌
  1. 打开 GitHub 令牌设置，创建 Fine-grained token。
  2. Repository access 选择 Only select repositories，仅选择 howard-notes。
  3. Repository permissions 中将 Contents 设为 Read and write，设置有效期后生成。
  4. 将令牌粘贴到上方登录框。本站仅在当前页面内存中使用它；刷新或退出后需要重新登录。

文章库是公开的 GitHub 仓库。这里的“草稿 / 撤下”控制网站展示，已提交的原文及历史仍可在仓库查看。私人草稿请保存在本地。
