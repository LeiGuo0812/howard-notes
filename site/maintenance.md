## 在网页中维护

在管理页面点击“使用 GitHub 登录”，用博客所有者账号授权。无需复制令牌；密码和二次验证仅在 GitHub 官方页面输入。刷新后再次点击登录，授权过期时可点击“重新登录”，保留未保存的编辑。

“文章”中编辑原文，使用格式工具栏和实时预览。Ctrl / Cmd + S 存草稿；点击“发布”才更新网站。

“草稿箱”可继续编辑、删除或发布草稿。已发布文章存草稿时保留原页面，发布后才替换原文，网址不变。取消编辑会放弃未保存的改动，保留已有草稿。

“图片”支持多选上传，也可在正文中直接粘贴剪贴板图片。图片上传成功后插入外链，默认保存在 `pic_cloud_gl/img`；单图不超过 10 MiB。

“页面设置 → 图片托管”可修改仓库、目录和分支。仓库需公开；点击“仓库授权”允许登录应用访问图片仓库，保存授权后重新登录。上传图片不会自动发布文章，已有图片链接不随托管设置更改。

“页面设置”中管理专题、模块顺序与显示状态、首页布局、导航、页脚和关于页。专题改名保持文章归属和网址不变。页面设置单独保存，不改写文章正文。

“创建日期”可调整笔记时间；修改正文会自动更新修改日期。首页热图按创建和最近修改统计，可切换年份，点击日期浏览对应笔记。

## 在 Obsidian 中维护

日常公开文章位于本地“博客发布 / 原文库 / notes”目录，按原笔记的目录结构排列。这里和网页管理使用的是同一份公开内容的两个副本。

每次开始编辑前同步一次，完成后再同步一次。同步工具会先获取网页更新，再比较上次同步、本地和网页三个版本。只有一端修改时自动同步；两端同时修改同一文件时停止并保存冲突副本。

本机命令和快捷入口见 Obsidian 中的“博客发布 / 发布说明”。网页无法直接读取电脑里的 Obsidian 文件，电脑未运行同步时，网页更新会留在 GitHub，等待下次同步。

## 新文章、草稿与撤下

网页中新建文章后，可以保存为草稿，确认后再公开发布。Obsidian 中新建的文件需要显式加入同步目录；新加入的文章默认不在网站展示，可在网页中切换发布状态。

仓库是公开的，保存到 GitHub 的草稿原文和历史也能被访问。“草稿 / 撤下”只控制网站展示。私人内容请留在公开文库以外。

## 原文与网站显示

首次迁移逐个校验 Markdown 文件的 SHA-256，公开源文件与被选中的本地原文件完全一致。原有目录中的文件不受迁移影响。

网站构建时为原文附加独立的显示信息，并解析 Markdown、双链、公式和图片；不会把这些渲染结果写回原文。指向未公开笔记的引用会保留文字并显示为不可点击的引用。外链图片继续使用原地址，是否可访问取决于原图床。
