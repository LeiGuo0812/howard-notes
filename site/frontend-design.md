# Liquid Glass 前端

沿用 Quartz 5、Preact、TypeScript 和 SCSS，不增加依赖。笔记原文、文章路由、搜索索引、分页和后台登录保持原有架构。

## 实现

- `quartz/styles/_liquid-glass.scss` 定义浅色、深色材质变量及玻璃和控件混入。没有 `backdrop-filter` 时先使用不透明底色，再通过 `@supports` 启用半透明材质。
- `quartz/styles/custom.scss` 统一悬浮导航、推荐卡片、紧凑列表、胶囊标签、热力图、搜索弹层和阅读排版。环境光位于页面边缘，不使用持续动画。正文和图谱不使用模糊。
- 导航的玻璃背板放在伪元素上，避免背景模糊为原生 Quartz 搜索弹层创建新的固定定位容器。
- 阅读正文默认最大宽度为 1040px，推荐卡片圆角为 20px；仍可在后台页面设置中调整。字体优先使用系统字体，中文回退到苹方、微软雅黑或 Noto Sans CJK。
- 小于 1000px 时目录与图谱折叠；小于等于 800px 时采用两行导航，减少模糊层。手机阅读位置按钮置于正文右侧留白中。
- 目录锚点使用响应式顶部滚动留白。交互过渡为 180ms，支持 `prefers-reduced-motion`。
- 移动目录展开不再触发缺少路由的全局重绘事件，避免原有图谱错误和控件重复初始化。

## 2026-10-01 验证

- `npm run build`、`npm run check`、`npm run test:publish`、`npm run verify:site` 通过；63 项测试、297 个 HTML 页面、172 篇文章。
- 172 篇笔记及本地原文库、发布库、同步基线共 688 份副本通过逐字节一致性校验。
- Chromium 和 Firefox 实际检查 390px、768px、1440px，浅色与深色的首页、文章列表、笔记详情和搜索。每个浏览器检查 27 个页面状态，均无页面横向溢出或 JavaScript 错误。
- 验证推荐刷新、每页 20 篇、分页、排序、列表检索、搜索快捷键与关闭、主题切换、折叠导航、图谱弹层、目录锚点和减少动画偏好。
- 后台真实页面预览、布局拖拽、模板切换、草稿恢复、上一版恢复、发布隔离及版本冲突检查通过；GitHub 写入使用模拟接口。到顶、到底按钮的鼠标、键盘、手机及 SPA 导航回归检查通过。
- 长标题、长链接、超长代码和宽表格通过浏览器内临时内容进行压力检查，不写入任何笔记；代码和表格仅在自身区域横向滚动。
- Firefox 禁用 `backdrop-filter` 后，实际验证桌面和手机、浅色和深色导航与搜索的完全不透明替代背景。
- 截图保存在 `output/playwright/glass-*.png`，该目录不提交到公开仓库。

未实测 Safari、真实 iPhone/iPad 或其他实体移动设备。构建中既有的 KaTeX Unicode 警告及循环转引提示继续保留，未改动原文以消除这些提示。
