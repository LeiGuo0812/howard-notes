# 1.去掉Bibliometrix包图上的logo
bibliometrix是通过在图片上添加图形添加logo的，把包data路径里的`logo.rda`文件替换成透明的图就可以了。
```r
load(file ='D:\\Softwares\\R-4.1.2\\library\\bibliometrix\\data\\logo.rda')#加载logo
newlogo <- matrix(data=0,nrow=800,ncol=800)#创建透明矩阵
logo[,,1] <-  newlogo#更新为透明logo
logo[,,2] <-  newlogo
logo[,,3] <-  newlogo
logo[,,4] <-  newlogo
save(logo,file='D:\\Softwares\\R-4.1.2\\library\\bibliometrix\\data\\logo.rda')#保存logo.rda
```
