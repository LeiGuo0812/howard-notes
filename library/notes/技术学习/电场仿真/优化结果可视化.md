电极位置优化以后，会生成 `msh`、`geo`、以及 `opt` 文件，可用于结果可视化

# msh 文件

- 包含了所有组成的 mesh，包括脑组织和电极（tag 1,2）以及眼球（tag 1006）
- 包含了所有场的数值（normal E，E 等）
- 不同的场用不同的 View 编码来代替，可以使用 gmsh 软件打开确认

一般我们想要去除眼球部分，可以使用 simnibs 的 api 完成：

```python
import os
import numpy as np
import simnibs
import simnibs.mesh_tools as msh
import matplotlib.pyplot as plt

# read result mesh
mesh = simnibs.read_msh('../results/optimization/distributed_less_electrodes.msh')

# mesh_origin = simnibs.read_msh('../data/m2m_MNI152/MNI152.msh')

# fetch only brain and electrode meshes (1006 eyeballs are ignored)
no_eyeball_mesh = mesh.crop_mesh(tags = [1,2])

# write new mesh for visualization
simnibs.mesh_io.write_msh(no_eyeball_mesh, 'no_eyeball.msh')
```

其中，我们想要修改某个场的 colormap，可以在此处修改，例如 `View[2].ColormapNumber = 10;`

可能的编号对应关系：

| 编号  | 名称               | 描述               |
| --- | ---------------- | ---------------- |
| 0   | Black            | 全黑色(通常不使用)       |
| 1   | Grayscale        | 灰度色谱             |
| 2   | Spectrum/Rainbow | 彩虹色谱(默认)         |
| 3   | Hot              | 热力图(黑-红-黄-白)     |
| 4   | Cool             | 冷色调(青-蓝-紫)       |
| 5   | Spring           | 春天色调(紫-黄)        |
| 6   | Summer           | 夏天色调(绿-黄)        |
| 7   | Autumn           | 秋天色调(红-橙-黄)      |
| 8   | Winter           | 冬 天色调(蓝-青)       |
| 9   | Bone             | 骨色(黑-蓝-白)        |
| 10  | Cool-Warm        | 冷暖色调(蓝-白-红)      |
| 11  | HSV              | HSV色彩空间          |
| 12  | Jet              | Jet色谱(蓝-青-绿-黄-红) |

如果想要使用个性化的图谱，则需要自己生成 rgb 序列填入，从最小值到最大值的映射，同时注释掉对应层的 `ColormapNumber` 代码（使用 `\\`）
