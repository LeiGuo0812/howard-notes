#EEG #数据处理

[Time-frequency analysis using Hanning window, multitapers and wavelets - FieldTrip toolbox](https://www.fieldtriptoolbox.org/tutorial/timefrequencyanalysis/)

[mne.time\_frequency.tfr\_multitaper — MNE 1.6.0 documentation](https://mne.tools/stable/generated/mne.time_frequency.tfr_multitaper.html)


![](https://www.fieldtriptoolbox.org/assets/img/tutorial/timefrequencyanalysis/figure1.png)

Fieldtrip 中介绍了四种时频分析的方法：

- **Hanning taper, 固定窗长**
	- 固定窗长，频率分辨率在不同频率下不同：1/窗长
	- 500ms 窗长的频率分辨率为 2Hz，及其整数倍
	- 因此频率选择范围必须是频率分辨率的整数倍 （如 500 ms 窗长，频率选择 2:2 :30）
- **Hanning taper, 频率相关窗长**
	- 窗长随着频率的增加而降低，便于发现更短时间内的能量变化，提高分辨率
	- 一般需要定义的是每个窗口内，需要包含对应频率的周期数
- **Multitaper**
	- 在进行傅里叶变换之前，通过应用一系列预定义的窗函数（如 Slepian 函数）来局部化原始信号，并对每个局部化信号进行傅里叶变换，然后对结果进行平均，可以提高估计的准确性和减少频谱泄漏。
	- 可以结合固定窗长的 stft 或频率依赖窗长，由研究者决定
	- 一般需要定义的是频率平滑的宽度，`cfg.tapsmofrq` ，可以设置为 `cfg.tapsmofrq  = 0.4 *cfg.foi`，平滑宽度越长，用到的 taper 越多
- **Morlet wavelets**
	- 使用小波，一般需要定义小波的宽度，小波宽度越小，时间分辨率越高，但频率分辨率越低
	- 小波分析也可以使用固定窗长和频率依赖的窗长（一般使用频率依赖窗长）
