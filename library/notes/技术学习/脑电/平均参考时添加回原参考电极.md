#EEG #预处理

有时使用了 1020 系统内的电极作为参考电极，在转换为平均参考前，可能需要将该电极重新加回到电极中去。

# EEGlab 中的做法：

[b. Re-referencing - EEGLAB Wiki]( https://eeglab.org/tutorials/05_Preprocess/rereferencing.html )

使用代码：
[Makoto's useful EEGLAB code - SCCN](https://sccn.ucsd.edu/wiki/Makoto%27s_useful_EEGLAB_code#How_to_add_the_initial_reference_electrode_back_by_average_referencing_.2803.2F10.2F2021.29)
(## Retaining the reference channel)

```matlab
EEG = pop_select( EEG, 'nochannel',{'IOLeft','IORight'});

n_chan = EEG.nbchan;
script_path = 'G:/MRItoolbox/eeglab2022.1';

EEG=pop_chanedit(EEG, 'append',n_chan,'changefield',{n_chan+1,'labels','AF'},'lookup',[script_path '/plugins/dipfit/standard_BEM/elec/standard_1005.elc']);

EEG = pop_reref( EEG, [],'refloc',struct('labels',{'AFz'},'type',{''},'theta',{0.16407},'radius',{0.36846},'X',{80.771},'Y',{-0.2313},'Z',{35.417},'sph_theta',{-0.16407},'sph_phi',{23.6767},'sph_radius',{88.1951},'urchan',{n_chan+1},'ref',{''},'datachan',{0}));

```

> Note that this approach causes effective rank deficiency, so this process needs to be done AFTER clean_rawdata (). pop_runica () has its own rank checker so no problem.
