# 1.脑影像坐标系统

![](https://cdn.nlark.com/yuque/0/2020/png/1210419/1587641255600-a27a38e6-8961-4ea6-bbd7-af4445dfee1e.png)

![](https://cdn.nlark.com/yuque/0/2020/png/1210419/1587641433827-9d9a8cc0-26b9-4c28-8e95-75d8c77f3f63.png)

-   在磁共振脑影像坐标系中，左右方向为Y轴，从左到右坐标增大
-   前后方向为Y轴，从后向前坐标增大
-   上下方向为Z轴，从下到上坐标增大
-   坐标系有两种表示方法

-   毫米坐标系（每个单位为1mm，左侧、后方、下方为负值，右侧、前方、上方为正值）
-   体素坐标系（每个单位为1个体素，没有负值，在各坐标轴上从1开始，到体素个数最大值）
