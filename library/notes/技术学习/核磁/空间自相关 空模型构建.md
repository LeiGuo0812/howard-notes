# 概论

构建空间自相关空模型有几个要素要考虑：
1. 数据是基于 volume 的数据还是 surface 的数据
2. 数据是 dense 的还是基于 ROI 分割的
3. 生成空模型的算法是什么

目前可以用于空间自相关图生成的软件包括：
1. BrainSMASH
2. neuromaps
3. brainstat
4. Juspyce

# BrainSMASH

- volmue ✓
- surface ✓
- dense ✓
- ROI ✓
- 算法：base/sample

## 输入：

1. 脑区（volume/surface 向量，可 dense 或 parcell
2. 距离矩阵（由 connectome workbench 获取）

其中，假如脑区中有 N 个值，则距离矩阵是一个 N × N 的矩阵

```python
base = Base(x=brain_map_file, D=dist_mat_file)
surrogates = base(n=1000)
```

surrogates 即一个 numpy 数组，置换次数×脑区数

如果添加了 `resample=True` ，则生成的空模型图完全从原始值中抽样，但不推荐，通常会降低代理映射的自相关与实际脑图的自相关的匹配程度

### dense 数据的特殊性

由于 dense 数据计算的是 voxel-wise 或 vertex-wise 的距离，因此距离矩阵会非常大，BrainSMASH 使用了两种方式来解决该问题：

1. 内存映射数组（memory-mapped arrays）
2. 随机抽样（random sampling）

```python
# construct memory-mapped arrays
from brainsmash.mapgen.memmap import txt2memmap
dist_mat_fin = "LeftDenseGeodesicDistmat.txt"  # input text file
output_dir = "."  # directory to which output binaries are written
output_files = txt2memmap(dist_mat_fin, output_dir, maskfile=None, delimiter=' ')

output_files = {'distmat': '/pathto/output_dir/distmat.npy',
                'index': '/pathto/output_dir/index.npy'}

# estimate null maps with random sampling
from brainsmash.mapgen.sampled import Sampled
brain_map_file = "LeftDenseMyelin.txt"  # use absolute paths if necessary!
dist_mat_mmap = output_files['distmat']
index_mmap = output_files['index']
sampled = Sampled(brain_map_file, dist_mat_mmap, index_mmap)

surrogates = sampled(n=10)
```
