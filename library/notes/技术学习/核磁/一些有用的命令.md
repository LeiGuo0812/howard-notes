# FSL

## 切片汇总、质控
`slicesdir *.nii` 将目录下所有的 nii 文件进行切片、汇总，并生成一个文件夹和 html 文件，所有图像的切片和汇总信息都在其中

## 快速脑切片图
`slicer img.nii.gz -a output.png` 对一张脑图快速切片，生成三个方向上的切片。用-s 选项来设置切片间隔，-x,-y,-z 选项来设置切片位置，-L 或者-R 选项来设置左右半球的显示顺序等
