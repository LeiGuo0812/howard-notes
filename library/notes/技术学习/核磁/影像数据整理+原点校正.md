#linux #影像 #数据处理

总结Linux系统下对原始影像数据进行转换和处理的方法。

因为西门子等机器扫描的结果会出现同名重复的序列影像，**但一般最大的文件的是我们需要的**，所以可以用这一点来进行分类。主要用到的命令有`du`, `sort`, `sed`，`awk`等。

# 1.数据转换

一般使用for循环对所有被试的数据目录进行转换，可以使用`dcm2niix`转换，同时通过 .json文件获取更多信息。

可以进入所有被试文件夹的父目录，使用`ls ./ > list.txt`生成一个被试目录列表

# 数据转换

```bash
for i in `cat list.txt`;do dcm2niix -i y -z y $i; done
```

- `-i` **忽略 localizer 和 derivatives**
- `-z` 压缩为 .nii.gz 文件

这样每个被试所有模态的转换后的数据，都统一存放到了被试文件夹内

# 2. 数据整理

## 2.1 结构像和fMRI

可以通过nii文件大小来协助文件选择，首先使用 `du` 和`sort`，结合文件关键词来进行文件大小排序，使用`sed`和`awk` 排序结果的行列进行选择。

例如：

```bash
# 搜索名称中含有MPRAGE的nii文件的最大的文件路径
du data/subj_path/*MPRAGE*.nii | sort -nr | sed -n '1p' | awk '{print $2}'
```

-   `du [file]`：查看文件大小，**默认用byte大小，如果需要转换成可读形式，加参数**`-h`**，但与sort联用时**`sort`**函数也要使用**`-h`**参数（使用容量大小），如果**`du`**不用**`-h`**参数，则**`sort`**要使用**`-n`**参数（使用数字大小）**；`--max-depth`可设置最大搜索深度；`-s`只显示当前文件夹总大小；`du`的输出是一个多行2列的文本，第一列是大小，第二列是文件路径
-   `sort -nr`：排序，`-n`依据数字大小排序，`-h`依据容量大小排序；`-r`倒序排列（从大到小）
-   `sed -n '1p'`：列出文本的第一行
-   `awk '{print $2}'`：列出文本的第二列

## 2.2 DWI等数据整理

DWI等数据比其他模态多了bvec和bveal的信息，所以要一起选择和拷贝，通过字符串截取的方式来找到bvec和bval文件

[https://blog.csdn.net/qq_26442553/article/details/79916527](https://blog.csdn.net/qq_26442553/article/details/79916527)

```
# i 是不同的subj_path
for i in `cat list.txt` 
do
dwi=`du data/$i/*DTI*.nii | sort -nr | sed -n '1p' | awk '{print $2}'`
bvec=${dwi%\.*}.bvec
bval=${dwi%\.*}.bval
cp ${dwi} sort/DWI/$i/DWI.nii
cp ${bvec} sort/DWI/$i/bvec
cp ${bvec} sort/DWI/$i/bval
done

```

可以后面再用`gzip`进行打包

# 3 整理后验证

可以用 `du -ah --max-depth 2`命令查看文件夹内的数据大小来验证

对于纵向数据，可以做一些比较，**避免session之间的复制错位**：

-   converted数据内的前后比较，看图像是否完全相同（避免重复复制）
-   raw和converted数据间的同session比较，确保复制顺序没有错位
-   raw和converted数据间的不同session交叉比较

# 4. 方向/原点校正

SPM可以使用Display进行手动原点校正：

[https://andysbrainbook.readthedocs.io/en/latest/SPM/SPM_Short_Course/SPM_07_SettingTheOrigin.html](https://andysbrainbook.readthedocs.io/en/latest/SPM/SPM_Short_Course/SPM_07_SettingTheOrigin.html)

**简要步骤：**

-   打开SPM12
-   选择Display，选择文件

![](https://cdn.nlark.com/yuque/0/2022/png/1210419/1659432750661-fc21f81a-8cfa-4533-bfbe-aaa24390d694.png)

-   如果大脑的方向有明显的偏移，可以通过 pitch, roll, yaw 三个选项调整大脑在 x, y, z 三个轴上的旋转程度，可以从 1e-2 的量级开始尝试，逐渐调整。
-   将corsshairs移动到前联合位置，点击 Set Origin，将前联合设置为原点，再点击Reorient，将设置保存

![](https://cdn.nlark.com/yuque/0/2022/png/1210419/1659433038267-3f2ef0f9-6c2c-4564-a076-e16f930245cc.png)

![](https://cdn.nlark.com/yuque/0/2022/png/1210419/1659433189514-eeb721aa-bf08-4e46-a109-58e49bfb5acd.png)

-   可以选择是否保存转换矩阵，用于后续读取

![](https://cdn.nlark.com/yuque/0/2022/png/1210419/1659433245757-35d91444-1762-4955-b043-389f04262083.png)

-   如果需要保存，选择 YES，设置保存路径即可，不保存选择 NO，完成原点校正
