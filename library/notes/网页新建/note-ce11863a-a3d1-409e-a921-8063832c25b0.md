优先级说明：

| 优先级 | 含义 |
| --- | --- |
| P0 | 可能导致直接退稿、行政退回、伦理问题或严重可信度损害 |
| P1 | 很可能被审稿人要求大修或质疑主要结论 |
| P2 | 影响专业性、可读性或出版流程，但通常不是致命问题 |

# 一、低级错误与行政错误检查表

这些错误看似低级，但最容易给编辑和审稿人留下“不严谨”的印象。投稿前应优先逐项核对。

## 1. 文件版本与上传错误

| 问题类型 | 检查项 | 具体核对 | 常见错误 | 优先级 |
| --- | --- | --- | --- | --- |
| 文件版本 | 是否上传最终版本 | 确认上传的是最终定稿，而不是草稿、返修前版本或带批注版本 | 上传错文件、旧版本、未清洁版本 | P0 |
| 文件版本 | 文件名是否清楚 | 文件名包含 manuscript、figure、supplement、cover letter 等清晰标识 | 文件名混乱，如 final_final_revised2.docx | P2 |
| 修订痕迹 | 是否删除 Track Changes | Word 中关闭修订并接受所有修改 | 稿件中保留修改痕迹 | P0 |
| 批注 | 是否删除评论 | 删除所有 reviewer 内部讨论、作者备注、TODO | 留下 “check this later”“need cite” 等批注 | P0 |
| 隐藏信息 | 是否检查文档属性 | 检查 Word/PDF 元数据、作者名、机构、路径信息 | 双盲审稿中泄露作者身份 | P0 |
| 文件格式 | 是否符合期刊要求 | Word、LaTeX、PDF、TIFF、EPS、JPEG 等格式是否符合要求 | 图像格式不接受，系统退回 | P1 |
| 文件完整性 | 文件是否能打开 | 在另一台电脑或 PDF 阅读器中打开确认 | 文件损坏、图表丢失 | P0 |
| 文件大小 | 是否符合上传限制 | 压缩图像或拆分 supplement | 文件过大上传失败 | P2 |
| 压缩包 | 是否不误传压缩包 | 若系统要求单独上传，则不要上传 zip | 系统无法识别 | P2 |

| 作者姓名 | 拼写是否准确 | 英文名、缩写、连字符、大小写 | 姓名拼写错误影响索引 | P0 |

| ORCID | 是否正确填写 | 尤其通讯作者和第一作者 | ORCID 对应错误作者 | P2 |

## 4. 正文低级一致性错误

| 问题类型 | 检查项 | 具体核对 | 常见错误 | 优先级 |
| --- | --- | --- | --- | --- |
| 样本量一致性 | 摘要、方法、结果、图表中的 n 是否一致 | 主样本、各组样本、子分析样本分别核对 | 摘要 n=120，表格 n=118 | P0 |
| 组名一致性 | 疾病组、对照组名称是否统一 | MDD、HC、BD、SZ 等缩写统一 | patient group、clinical group、MDD group 混用 | P1 |
| 时间点一致性 | baseline、follow-up 时间是否一致 | 1 month、4 weeks、30 days 不要混乱 | 方法写 8 周，结果写 6 周 | P1 |
| 变量名称 | 量表、脑区、指标名称是否一致 | HAM-D、HDRS、BDI 等不要混用 | 同一量表多个名称 | P1 |
| 缩写 | 首次出现是否定义 | 摘要和正文通常分别定义 | 未定义缩写，或定义后不用 | P2 |
| 单位 | 单位是否完整一致 | mmol/L、ms、Hz、mm³、μV、mg/kg | 同一指标单位前后不同 | P1 |
| 小数位 | 小数位是否统一 | 均值、SD、p 值、CI 统一规则 | 表格中 1 位、2 位、3 位混用 | P2 |
| 百分比 | 百分比是否能对应 n | 重新计算所有百分比 | 23/100 写成 24% | P1 |
| 方向性 | 结果方向是否一致 | “higher”“lower”“increased”“decreased” 与数据一致 | 图中下降，正文写升高 | P0 |
| 统计显著性 | p 值与文字是否一致 | p<0.05 才写 significant | p=0.08 写 significant | P0 |
| p 值格式 | 是否避免 p=0.000 | 应写 p<0.001 | p=0.000 | P2 |
| 负零 | 是否去除 -0.00 | 四舍五入后检查 | β=-0.00 | P2 |
| 置信区间 | CI 是否与效应方向一致 | OR、β、mean difference 与 CI 方向匹配 | OR>1 但 CI 全小于 1 | P0 |
| 统计自由度 | df 是否合理 | t、F、χ² 的 df 与样本量一致 | df 超出样本逻辑 | P1 |
| 结果引用 | 正文是否引用所有图表 | Figure 1、Table 1、Supplementary Table S1 | 有图表未被正文引用 | P2 |
| 编号顺序 | 图表是否按出现顺序编号 | Figure 1 先于 Figure 2 | 先出现 Figure 3 | P2 |
| 补充材料引用 | Supplement 编号是否正确 | Table S1、Figure S2 与文件一致 | 正文引用 Table S3，但补充中没有 | P1 |

## 5. 图表低级错误

| 问题类型 | 检查项 | 具体核对 | 常见错误 | 优先级 |
| --- | --- | --- | --- | --- |
| 图编号 | 图编号是否连续 | Figure 1, 2, 3 | 缺 Figure 2 | P2 |

| 坐标轴 | 坐标轴是否有名称和单位 | x/y axis label | 只有数值，没有指标名 | P1 |
| 误差线 | 是否说明 SD、SEM 或 CI | 不要只画 error bar 不解释 | 误差线含义不明 | P1 |
| 颜色 | 是否颜色可区分 | 色盲友好；黑白打印可读 | 颜色太接近 | P2 |
| 分辨率 | 是否符合期刊要求 | 通常 300 dpi 或更高，按期刊要求 | 图像模糊 | P1 |
| 字体 | 图中文字是否可读 | 缩小到版面尺寸后仍可读 | 字太小 | P2 |
| 统计标记 | 星号含义是否说明 | * p<0.05, ** p<0.01 等 | 星号无说明 | P1 |
| 多重校正 | 图中 p 值是否说明校正 | uncorrected、FDR-corrected、FWE-corrected | 图中只标 p，不说明校正 | P1 |
| 图中 n | 每组 n 是否标注 | 尤其有缺失或子样本分析时 | 图中 n 与正文不一致 | P1 |
| 显微图 | 是否有 scale bar | 显微、组织、细胞图必须核对 | 缺 scale bar | P1 |
| 脑图 | 方向和阈值是否清楚 | left/right、slice coordinate、threshold | 左右脑方向不明 | P1 |
| Western blot | 是否说明裁剪和归一化 | 原始膜、loading control、重复数 | 图像拼接不透明 | P0 |
| 图像处理 | 是否无不当增强 | 对比度调整一致、无选择性修改 | 图像伦理风险 | P0 |
| 表格标题 | 表题是否准确 | 能概括表格内容 | 表题和内容不匹配 | P2 |
| 表注 | 缩写和统计方法是否说明 | 所有缩写在表下注明 | 表格缩写未解释 | P2 |
| 表格单位 | 每个变量单位是否清楚 | 年龄、病程、剂量、浓度等 | 单位缺失 | P1 |
| 表格排版 | 是否跨页混乱 | PDF 中表格不断裂或错位 | 投稿 PDF 表格错乱 | P1 |

# 三、科学问题与文章逻辑检查表

| 顺序 | 检查层级 | 目的 |
| --- | --- | --- |
| 1 | P0 合规项 | 先排除伦理、注册、作者、利益冲突、数据声明等直接退稿风险 |
| 2 | 主要结论 | 检查结论是否被数据支持，是否过度因果化 |
| 3 | 方法与统计 | 检查样本、诊断、混杂、多重比较、缺失数据、模型假设 |
| 4 | 精神神经科学专项 | 检查药物、共病、头动、ROI、动物实验单位、批次效应等 |
| 5 | 图表与数字一致性 | 逐个核对 n、p、CI、效应量、百分比、图表编号 |
| 6 | 低级格式错误 | 修订痕迹、批注、文件名、PDF、投稿系统信息 |
| 7 | Cover letter 与上传文件 | 最后确认投稿包完整 |

最关键的是：**低级错误不等于低风险**。样本量不一致、上传错版本、双盲泄露、图表数字冲突、伦理声明缺失，这些问题本身不复杂，但会直接削弱编辑和审稿人对整篇文章的信任。
