# Introduction

- 介绍研究对象的定义、特点、该问题的普遍性或严重性（全球负担、流行病学数据）和危害，为什么值得关注
- 介绍研究的主要变量的定义及其在研究对象中的作用
- 介绍至少一种相关机制/理论
- 介绍当前领域研究空白/前人研究不足
- 介绍当前研究的目的（补充当前理论/推翻当前理论）和意义
- 介绍研究假设

# Methods

依据consort 声明进行逐项填写

- 被试招募流程，伦理情况，注册号
- 研究设计，分配比例，分析性质（等效性、优效性、非劣效性、探索性等）
- 研究方案更改
- 入排标准
- 干预设置及研究细节
- 主要、次要结局指标介绍及其收集
- 副作用收集
- 样本量计算
- 随机化
    - 随机序列产生
    - 分配隐藏
- 盲法
- 统计分析
    - 主要/次要分析的主要统计方法
    - 缺失值的处理方法
    - 其他分析，区分预定义分析和 post-hoc 分析

# Results

依据 consort 声明进行逐项填写

- 研究流程，各个阶段被试数量（随机化，接受预期干预，纳入最终分析），各组缺失或脱落情况及原因。
- 被试招募、干预和随访时间范围，如需要，说明实验为何停止或终止
- 基线数据（Table. 1）
- 主要结局、次要结局结果，报告精准性（效应量或 95%CI）
- 副作用报告
- 其他分析，区分预定义分析和post-hoc 分析

# Discussion

- 简要总结研究内容、结果和主要贡献
- 介绍主要结果，说明是否符合假设，并与既往研究（细化到与自己研究直接相关的问题）和理论框架进行联系，介绍研究优势，说明结果意义（补充/推翻/解决争议 现有理论），探讨潜在机制
- 介绍次要分析结果对主要分析的作用，说明结果意义，强化了主要结果，还是进一步提示需要谨慎解释，解释潜在的机制
- 总结研究优势，升华指导意义
- 研究局限性（研究设计、样本针对性、机制全面性等）
- 未来展望（基于局限性）

# Attention

- 注意不要出现贬低、激烈批评既往研究结果，而是客观分析既往研究的不足和欠缺
- Results 只报告结果，不进行额外解释
- 不要过度泛化研究意义
- 讨论应围绕最初的研究问题，针对问题本身的相关影响因素展开讨论（如预测因素、疗效等等）
