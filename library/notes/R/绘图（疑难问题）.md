## 1.在ggplot2中对因子变量重新排序
在ggplot2的图像上，变量的排列顺序由因子级别决定，而不是数据框中看到的顺序。使用 `sort()` 或 `arrange()` 函数可以对数据框里的数据进行排序，但 对ggplot2图像的输出不会有任何影响 。有几种方式可以实现对因子的重新排序。
<a name="mv2gF"></a>
### 1.forcats包
函数 `fct_reorder()` 可以将某因子（factor）按照另一列对应的值来进行排序。假设有数据框df, 因子型变量var, 数值型变量n， **每个var都对应一个n** ：
```r
#默认按照n的值，将var从小到大排列
#注意：使用了coord_flip()翻转坐标轴后，n大的var在上方（离原点远的地方）
fct_reorder(df$var,df$n)

#使用des()，按照n的值，将var从大到小排列
fct_reorder(df$var,des(df$n))

#注意：fct_reorder()只返回重新排序后的因子而不改变原始数据框，
要使用赋值 <- 或 mutate() 函数改变原始值。（管道符%>%也很好用）
```


**如果每个var下对应了多个n的值** ， `fct_reorder()` 可以指定对 n 使用何种函数来确定var的顺序，默认使用中位数，但也可以指定每个因子下数值的个数（样本量）来进行排序：
```r
#使用中位数
mpg %>%
  mutate(class = fct_reorder(class, hwy, .fun='median'))

#使用样本量
mpg %>%
  mutate(class = fct_reorder(class, hwy, .fun='length' ))
```

**可以使用 **`fct_relevel()`** 函数自定义因子顺序：
```r
df %>%
  mutate(var = fct_relevel(var, 
            "level_1", "level_2", "level_3",...)
```

<a name="k2S2p"></a>
### 2.dplyr包
dplyr包中的 `mutate()` 函数可以创建新变量或修改现有变量，因此可以用该函数来 **重新创建一个有特定顺序的因子变量** （注意，机制是重新创建，而不像 `fct_reorder()` 函数一样是修改原来的变量）。<br />同样地，假设有数据框df, 因子型变量var, 数值型变量n， **每个var都对应一个n** ：
```r
df %>%
  arrange(n) %>%    # First sort by n. This sort the dataframe but NOT the factor levels
  mutate(var=factor(var, levels=var)) %>%   # This trick update the factor levels
```

- 使用 `arrange()` 函数将数据框顺序按n从小到大排列，因子var也随之改变，但该变量中的因子顺序没有变化。
- 使用 `mutate()` 函数和 `factor()` 函数组合，将变量var中的因子 **重新生成** ，其中具体值为排序后的var（决定因子有哪些），因子水平（决定因子顺序）是排序后的var，实现因子顺序的重排。



**也可以自定义因子水平:** 
```r
df %>%
  arrange(n) %>%
  mutate(var = factor(var, levels=c("level_1", "level_2", "level_3",...)))
```

<a name="7M7kU"></a>
### 3.base包
R的基础包里也提供了对因子型变量的重排函数 `reorder()` ，类似于 `fct_reorder()` ，第一个参数传入要重排的因子型变量，第二个参数传入排序依据（通常为数值型变量），第三个参数传入对数值型变量进行运算的函数，如 `median()` 、 `mean()` 、 `length()` 等：
```r
# reorder is close to order, but is made to change the order of the factor levels.
mpg$class = with(mpg, reorder(class, hwy, median))
```

这里的 `with()` 函数声明了其第二个参数（ 即`reorder()` ）作用的数据环境，即重排这一函数是在mpg数据集中发生的，这样可以避免使用 `$` 符使代码看上去简洁：
```r
with(mtcars, mpg[cyl == 8  &  disp > 350])
    # is the same as, but nicer than
mtcars$mpg[mtcars$cyl == 8  &  mtcars$disp > 350]
```

## 4.在坐标轴上显示样本量
![](https://cdn.nlark.com/yuque/0/2020/png/1210419/1585743973233-37b21a12-6e3c-48b3-b702-b29cd4e9cd3f.png#averageHue=%23fcfcfc&crop=0&crop=0&crop=1&crop=1&height=243&id=O6Ms0&name=&originHeight=960&originWidth=1536&originalType=binary&ratio=1&rotation=0&showTitle=false&size=0&status=done&style=none&title=&width=389)

对于离散变量，其在坐标轴的映射就是分类名称，要多显示一些信息，只需要拼接出所需的字符串，然后作为 x 轴的映射即可。
```r
# Libraries
library(ggplot2)
library(dplyr)
library(hrbrthemes)
library(viridis)

# create a dataset
data <- data.frame(
  name=c( rep("A",500), rep("B",500), rep("B",500), rep("C",20), rep('D', 100)  ),
  value=c( rnorm(500, 10, 5), rnorm(500, 13, 1), rnorm(500, 18, 1), rnorm(20, 25, 4), rnorm(100, 12, 1) )
)

# sample size
#计算每组的样本量
sample_size = data %>% group_by(name) %>% summarize(num=n())

# Plot
data %>%
#虽然data和sample_size长度不一，但自动按name匹配，并把长度扩展到等长
  left_join(sample_size) %>%
#产生新的字符串作为x轴的映射
  mutate(myaxis = paste0(name, "\n", "n=", num)) %>%
#重点在此处：映射x轴为重新产生的变量
  ggplot( aes(x=myaxis, y=value, fill=name)) +
    geom_violin(width=1.4) +
    geom_boxplot(width=0.1, color="grey", alpha=0.2) +
    scale_fill_viridis(discrete = TRUE) +
    theme_ipsum() +
    theme(
      legend.position="none",
      plot.title = element_text(size=11)
    ) +
    ggtitle("A Violin wrapping a boxplot") +
    xlab("")
```

## 1.每个组只有一个观测时的因子变量映射

  在绘制**重复测量数据**的 time × group 图时，一般思路是把每组在每个时间点的数据的均值计算出来，整理成数据框，然后进行绘制，以数据PHQ为例：
  
```r
> PHQ
# A tibble: 4 x 3
  group        time  PHQ_9
  <fct>        <fct> <dbl>
1 non-response pre    6.87
2 response     pre    5.23
3 non-response post   8.26
4 response     post   1.69
```

整理数据的过程中使用了 tidyverse 系列函数，如 `filter()` 选取符合条件的行, `group_by()` 对数据分组, `summarise()` 计算分组后的均值, `gather()` 将宽数据转为长数据方便画图， `mutate()` 函数联用 `fct_relevel()` 改变因子顺序，以改变画图时的位置等。

此时我希望得到两组前后变化的折线图，并用线型代表每个组，于是使用代码：
```r
ggplot(data = PHQ, aes(x = time, y = PHQ_9)) +
  geom_line(aes(linetype = group))
```
但是报错：
```r
geom_path: Each group consists of only one observation. Do you need to adjust the group aesthetic?
```
意思是按照 linetype 分组，每组只有一个观测值。图像也无法显示：<br />![image.png](https://cdn.nlark.com/yuque/0/2020/png/1210419/1590388831605-5b6a96c9-0fcb-4d6d-8eaa-bc56255d89ac.png#averageHue=%23fefdfd&crop=0&crop=0&crop=1&crop=1&height=212&id=LH6kh&margin=%5Bobject%20Object%5D&name=image.png&originHeight=455&originWidth=707&originalType=binary&ratio=1&rotation=0&showTitle=false&size=13593&status=done&style=shadow&title=&width=330)

但是在 `geom_line()` 中映射 `aes(group = group)` 后，线可以成功分组，图像也显示出来：
```r
ggplot(data = PHQ, aes(x = time, y = PHQ_9)) +
  geom_line(aes(group = group))

```
![image.png](https://cdn.nlark.com/yuque/0/2020/png/1210419/1590388923361-15b6f3af-6625-462a-98e4-d88875f5bc90.png#averageHue=%23fdfdfd&crop=0&crop=0&crop=1&crop=1&height=220&id=npYyQ&margin=%5Bobject%20Object%5D&name=image.png&originHeight=455&originWidth=707&originalType=binary&ratio=1&rotation=0&showTitle=false&size=13362&status=done&style=shadow&title=&width=342)

```r

  geom_line(aes(group = group, linetype = group))
```

## 4.图像注释使用latex语法(斜体，粗体等)
有些图像要求在图像上注释显著性等信息，统计量的符号要斜体，而统计值不需要，这时候使用 `geom_text` 就不方便了，要用 `annotate` 

```r
library(ggplot2)

mtcars %>% 
  ggplot(aes(x = wt, y = drat, color = cyl)) + 
  geom_point() + 
  geom_smooth(method = 'lm', se = F, color = 'gray', size = 0.5) + 
  annotate('text', 
           x=c(4.5,4.5), y=c(4.6,4.75), 
           label = c('italic(p) < 0.001','italic(r) == -0.712'),
           size = 5, hjust = 0, 
           parse = T) + 
  theme_light()
```

![image.png](https://cdn.nlark.com/yuque/0/2021/png/1210419/1610459831515-e96f9c21-b550-4eab-a1f0-917b26bf2365.png#averageHue=%23fcfcfc&crop=0&crop=0&crop=1&crop=1&height=286&id=mDKMt&margin=%5Bobject%20Object%5D&name=image.png&originHeight=424&originWidth=579&originalType=binary&ratio=1&rotation=0&showTitle=false&size=21097&status=done&style=none&title=&width=391)<br />

## 7. 结合管道和ggsave() 一行代码生成保存gg对象
直接将`ggplot2()`函数生成的绘图通过管道传递给 `ggsave()`会报错，如果需要结合管道和`ggsave()`，则需要用括号将整个`ggplot2()`的绘图代码括起来，再用管道传给 `ggsave()`

```r
library(magrittr)
library(ggplot2)
data("diamonds")

(ggplot(diamonds, aes(x=cut)) +
    geom_bar()
) %>% 
  ggsave("plot.png", . , dpi = 100, width = 4, height = 4)
```

## 2.基础绘图保存错误解决
可以用 `pdf()` /`svg()` /`jpeg()` + `dev.off()`函数来保存基础图形，但有时用储存了图像的变量代替绘图函数时，保存出来的可能是一张空图，这时在外面套一个 `print()` 即可。
