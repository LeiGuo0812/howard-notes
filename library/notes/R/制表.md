# gtsummary 输出统计结果表

[Presentation-Ready Data Summary and Analytic Result Tables • gtsummary](https://www.danieldsjoberg.com/gtsummary/)

针对 `afex` 包 `mixed` 函数的统计结果，可以使用 `tbl_regression` 函数生成总结表：

```r
tbl_regression(mod$full_model) |> 
  add_global_p() |> 
  bold_labels() |> 
  as_gt() |> 
  gt::gtsave('./model_summary.docx')
```
