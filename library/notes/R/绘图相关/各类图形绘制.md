# 1. 棒棒糖图/棉棒图

![](https://cdn.nlark.com/yuque/0/2020/png/1210419/1585744687520-01715bb0-f938-43fe-9f34-8c44f40ab918.png#height=280&id=q72Jq&originHeight=1344&originWidth=1344&originalType=binary&ratio=1&size=0&status=done&style=none&width=280)

  

  本质上是点图和直线绘图的组合，要用到 `geom_point()` 函数和 `geom_segment()` 函数, `geom_segment()` 函数可以绘制点（x,y）到点（xend，yend）的直线，在棒棒糖图中，两个点即（x,0）和（x,y）。分别传入 `geom_segment()` 的映射即可。

  

```r

# Libraries

library(ggplot2)

  

# Create data

data <- data.frame(

  x=LETTERS[1:26],

  y=abs(rnorm(26))

)

  

# Plot

ggplot(data, aes(x=x, y=y)) +

#注意此处对geom_segment映射的定义，实质上是在确定直线的两端坐标

  geom_segment( aes(x=x, xend=x, y=0, yend=y), color="grey") +

  geom_point( color="orange", size=4) +

  theme_light() +

  theme(

    panel.grid.major.x = element_blank(),

    panel.border = element_blank(),

    axis.ticks.x = element_blank()

  ) +

  xlab("") +

  ylab("Value of Y")

```

  

## i.外观调整

通过对 `geom_point()` 和 `geom_segment()` 传入映射，可分别改变点和直线的外观

## ii.改变baseline

只需改变起始点的 y 坐标，即可改变棒棒糖的基线，如在映射中设置 y = 1

  

# 2.散点图/直方图等添加边际分布

![](https://cdn.nlark.com/yuque/0/2020/png/1210419/1585745947957-e7b53028-0d94-4184-99d7-d39a0808d999.png#height=314&id=u6iDQ&originHeight=1344&originWidth=1344&originalType=binary&ratio=1&size=0&status=done&style=none&width=314)

在散点图周围添加边际分布,需要用到 **ggExtra** 包中的 `ggMarginal()` 函数。先使用 `p <- ggplot()+geom_point()` 创建一个散点图 **p** ，然后使用 `ggMarginal(p, type = 'density')` ，添加边际分布。除了密度分布，也可以绘制直方图、箱线图。

  

```r

library(ggExtra)

# The mtcars dataset is proposed in R

head(mtcars)

# classic plot :

p <- ggplot(mtcars, aes(x=wt, y=mpg, color=cyl, size=cyl)) +

      geom_point() +

      theme(legend.position="none")

# with marginal histogram

p1 <- ggMarginal(p, type="histogram")

# marginal density

p2 <- ggMarginal(p, type="density")

# marginal boxplot

p3 <- ggMarginal(p, type="boxplot")

```

  

## i.外观调整

可以使用size、fill、color等参数控制边际分布图的外观。 `margins = c('both','x','y')` 控制分布显示轴。其他参数可通过 `?ggMarginal` 学习。

绘制雷达图需要用到 **fmsb** 包。数据输入格式比较特殊：每一列是一个数值型变量，第一行决定雷达图外圈的数值（一般是规定的上限max），第二行决定雷达图的内圈（一般是规定的下限min）,第三行填入每个变量的实际值。然后将数据框传入 `radarchart()` 函数即可。

data <- rbind(rep(20,10) , rep(0,10) , data)

## i.外观调整

The `radarchart()` function offers several options to customize the chart:

  

- Polygon features:

   - `pcol` → line color

   - `pfcol` → fill color

   - `plwd` → line width

- Grid features:

   - `cglcol` → color of the net

   - `cglty` → net line type (see [possibilities](https://www.r-graph-gallery.com/6-graph-parameters-reminder.html))

   - `axislabcol` → color of axis labels

   - `caxislabels` → vector of axis labels to display

   - `cglwd` → net width

- Labels:

   - `vlcex` → group labels size

  

# 4. 2D密度图

当数据量非常大的时候，使用**2D密度图**是呈现两个数值型变量关系的有用工具。

![](https://cdn.nlark.com/yuque/0/2020/png/1210419/1585972127624-35ed47de-174e-4bca-984f-b11336283f90.png#height=193&id=AXfFT&originHeight=1344&originWidth=1344&originalType=binary&ratio=1&size=0&status=done&style=none&width=193)

如图，数据量大时，散点图中的点会出现严重的重叠现象，不便展示。在2D密度图中，绘图区域被分割成许多小块，小块的颜色代表了落在该区域的散点数量。如此便避免了数据重叠的问题。此类图形可以向ggplot图形中添加 `geom_bin2d()` 或 `geom_hex()` 几何对象完成：

  

- `geom_bin2d()` 将绘图区域分割成矩形

- `geom_hex()` 将绘图区域分割成六边形

```r

#Create data

a <- data.frame( x=rnorm(20000, 10, 1.9), y=rnorm(20000, 10, 1.2) )

b <- data.frame( x=rnorm(20000, 14.5, 1.9), y=rnorm(20000, 14.5, 1.9) )

c <- data.frame( x=rnorm(20000, 9.5, 1.9), y=rnorm(20000, 15.5, 1.9) )

data <- rbind(a,b,c)

  

#plot 1

ggplot(data, aes(x=x, y=y) ) +

  geom_bin2d(bins = 70) +

  scale_fill_continuous(type = "viridis") +

  theme_bw()

  

#plot 2

ggplot(data, aes(x=x, y=y) ) +

  geom_hex(bins = 70) +

  scale_fill_continuous(type = "viridis") +

  theme_bw()

```

## i.外观调整

可以用 `bins` 参数来指定沿坐标轴将图形分割的精细程度。可以传入一个数字或 `c(n1,n2)` 形式的数字向量。

  

**使用** `geom_density_2d()`** 或 **`stat_density_2d()` **绘制2D分布：**

上面图像中，颜色代表的是样本的数量，因此是一种二D的直方图，同样地，也可以绘制2D的概率密度分布图，此时颜色代表的是样本出现在该区域的概率（范围0~1），可以选择绘制分布的 **轮廓** 、 **区域** 、或者 **栅格化** 的图形：

```r

# Show the contour only

ggplot(data, aes(x=x, y=y) ) +

  geom_density_2d()

# Show the area only

ggplot(data, aes(x=x, y=y) ) +

  stat_density_2d(aes(fill = ..level..), geom = "polygon")

# Area + contour

ggplot(data, aes(x=x, y=y) ) +

  stat_density_2d(aes(fill = ..level..), geom = "polygon", colour="white")

# Using raster

ggplot(data, aes(x=x, y=y) ) +

  stat_density_2d(aes(fill = ..density..), geom = "raster", contour = FALSE) +

  scale_x_continuous(expand = c(0, 0)) +

  scale_y_continuous(expand = c(0, 0)) +

  theme(

    legend.position='none'

  )

```

# 6.分面时其他数据作为背景

分面时，ggplot2在各个面上只显示本分组的数据，而其他组的数据被忽略掉:![image.png](https://cdn.nlark.com/yuque/0/2020/png/1210419/1587779935309-cba1f6ad-5fda-4579-be8b-51b8a36b8859.png#height=238&id=lxB1z&originHeight=630&originWidth=766&originalType=binary&ratio=1&size=60381&status=done&style=none&width=289)

如果希望其他组的数据可以作为背景一起展示，可以添加一层**不含分组变量数据**构成的图层：

```r

ggplot(data = iris,aes(x = Sepal.Length, y = Sepal.Width, color = Species)) +

  #添加一个散点图层，其中传入的数据没有分组变量"Species",颜色设置为灰色

  geom_point(data = iris[, -5],color = 'grey')+

  geom_point() +

  geom_smooth(method = 'lm') +

  scale_color_brewer(palette = 'Dark2') +

  theme_minimal() +

  facet_grid(. ~ Species)

```

```r

ggplot(iris, aes(x = Sepal.Width,

  geom_density()

```

在图层统计变换的时候，会生成两个隐藏变量，一个是计数count，一个是密度density，在映射的时候，选择密度这个变量，即可

- 绘制正态曲线

```r

x<-rnorm(3000,0,1)

funss<-function(x) {

  1/sqrt(2*pi)*exp(-1/2*x^2)

}

ggplot(NULL, aes(x=x))+

  geom_histogram(bins=20,aes(y=..density..))+

  stat_function(fun=funss,geom="line",colour='red')

```

这里的funss为标准正态分布的密度函数，用结果y=..density..来绘制频率分布直方图。在ggplot中，我们只输入了横坐标的值，在geom_histogram中，我们绘制了频率直方图并确定了组距，最后的stat_function确定了绘制的函数的形式。

# 8.绘制误差线

[Vertical intervals: lines, crossbars & errorbars](https://ggplot2.tidyverse.org/reference/geom_linerange.html)

  

绘制误差线时，一般来说误差线的宽度要比柱状图的宽度小，但这就造成了两者在使用dodge排列时，dodge的相对宽度不同，造成错位:

```r

df <- data.frame(

  trt = factor(c(1, 1, 2, 2)),

  resp = c(1, 5, 3, 4),

  group = factor(c(1, 2, 1, 2)),

  upper = c(1.1, 5.3, 3.3, 4.2),

  lower = c(0.8, 4.6, 2.4, 3.6)

)

  

p <- ggplot(df, aes(trt, resp, fill = group))

p +

 geom_col(position = "dodge") +

 geom_errorbar(aes(ymin = lower, ymax = upper), position = "dodge", width = 0.25)

```

![](https://cdn.nlark.com/yuque/0/2020/png/1210419/1598083281622-19a84c33-3934-49f0-9012-be5905b59995.png#height=304&id=HDBKE&originHeight=866&originWidth=1400&originalType=binary&ratio=1&size=0&status=done&style=none&width=492)

如果想要两者统一，则需要手动调整 dodge width：

```r

dodge <- position_dodge(width=0.9)

p +

  geom_col(position = dodge) +

  geom_errorbar(aes(ymin = lower, ymax = upper), position = dodge, width = 0.25)

```

![](https://cdn.nlark.com/yuque/0/2020/png/1210419/1598083454999-6c5c5471-acef-4836-8784-b9f2aa42e7ce.png#height=298&id=vrjwn&originHeight=866&originWidth=1400&originalType=binary&ratio=1&size=0&status=done&style=none&width=481)

  

当使用dodge2调整误差线位置时，还需要在误差线间增加 padding 来使之与柱状图对齐

```r

p +

geom_col(position = "dodge2") +

geom_errorbar(

  aes(ymin = lower, ymax = upper),

  position = position_dodge2(width = 0.5, padding = 0.5)

)

```

同理，如果在柱状图上添加蜂群图，可以使用其中的 dodge.width 参数调整位置
