将基线数据纳入模型自变量，因变量是后测值还是变化量，模型是否有区别。

只要你在模型右边（自变量部分）放入了基线（Pre）作为协变量，无论你左边（因变量）放的是 **Post** 还是 **Change (Post - Pre)**，你得到的**核心结果（即 Group 的 P 值、系数 t 值、以及中介效应的显著性）是完全一模一样的。**

### 1. 为什么它们是一样的？（数学证明）

让我们用简单的代数公式来看一下。

假设：

- $Y_{post}$ = 干预后的值
    
- $Y_{pre}$ = 基线值
    
- $X$ = 分组 (Group)
    
- $\epsilon$ = 误差
    

#### 模型 A：标准 ANCOVA (我之前推荐的)

$$Y_{post} = \beta_0 + \mathbf{\beta_1} X + \beta_2 Y_{pre} + \epsilon$$

- 这里我们关注 $\beta_1$，即组别效应。
    

#### 模型 B：Change ANCOVA (你现在问的)

$$Change = Y_{post} - Y_{pre}$$

模型公式为：

$$(Y_{post} - Y_{pre}) = \alpha_0 + \mathbf{\alpha_1} X + \alpha_2 Y_{pre} + \epsilon$$

我们将模型 B 的公式移项，把 $Y_{pre}$ 移到等号右边：

$$Y_{post} = \alpha_0 + \mathbf{\alpha_1} X + \alpha_2 Y_{pre} + Y_{pre} + \epsilon$$

$$Y_{post} = \alpha_0 + \mathbf{\alpha_1} X + (\alpha_2 + 1) Y_{pre} + \epsilon$$

**对比模型 A 和 移项后的模型 B：**

你会发现这两个公式是完全等价的！

- **组别效应 ($\beta_1$ vs $\alpha_1$)**：**完全相等**。这意味着干预效应的大小、标准误、t值和P值都不会变。
    
- **基线系数 ($\beta_2$ vs $\alpha_2$)**：这是唯一的区别。
    
    - 在模型 A (Post) 中，$\beta_2$ 反映的是 $Pre$ 和 $Post$ 的相关性（通常在 0 到 1 之间）。
        
    - 在模型 B (Change) 中，$\alpha_2$ 等于 $\beta_2 - 1$。它反映的是**均值回归的强度**（通常是负值）。
        

### 2. 在中介分析中意味着什么？

在中介分析 `mediate()` 中，也是同样的道理。

**Path a (X -> M):**

- 无论中介变量 $M$ 设为 `Post` 还是 `Change`，只要你控制了 `Pre`，自变量 `Group` 对 $M$ 的影响系数（$a$ 值）是完全一样的。
    

**Path b (M -> Y):**

- 模型：$Y \sim Group + M + Pre$
    
- 如果 $M = Post$：$Y = b \cdot Post + c \cdot Pre + ...$
    
- 如果 $M = Change$：$Y = b \cdot (Post - Pre) + c \cdot Pre + ... = b \cdot Post + (c-b) \cdot Pre + ...$
    
- 你会发现，$Post$ 前面的系数（即 $b$ 值，中介对结果的影响）依然保持不变。
    

### 3. 既然一样，为什么要用 Post 而不是 Change？

虽然数学上一样，但在科研惯例和解释上，**Post (ANCOVA)** 更常用，原因如下：

1. **便于解释 (Convention)**：
    
    - 当我们说“控制了基线后，两组在终点有差异”，这比较直观。
        
    - 如果用 Change，你需要解释“控制了基线后，两组的变化量有差异”，虽然也没错，但这时候基线的系数 ($\alpha_2$) 通常是负的（例如 -0.3），这会让非统计学专业的读者困惑：_“为什么基线越高，变化越小？”_（这就是均值回归，但在文章里解释起来比较绕）。
        
2. **避免“差分悖论”误区**：
    
    - 很多旧的研究喜欢直接用 $Change$ 但**不控制** $Pre$（即 $Change \sim Group$）。这是一种错误的做法。
        
    - 为了防止读者误以为你用了那种错误的方法，直接写 $Post \sim Group + Pre$ 可以非常明确地告诉审稿人：“我用的是 ANCOVA 模型”。
        

### 4. 给你的建议

**你可以放心地用 Post。**

如果你非常想用 Change，或者觉得用 Change 讲故事更通顺（例如：“干预导致了ALFF的**下降幅度**更大”），那么你可以使用 `Change ~ Group + Pre`。

**只要记住一点：**

**必须在自变量里加上 Pre (基线)。**

只要加了 Pre，无论因变量是 Post 还是 Change，你实际上都在做同一个正确的统计校正。审稿人看到的 P 值和中介效应结果将是一模一样的。
