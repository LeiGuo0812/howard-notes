# 相对于重复测量方差分析的优势

- 拟合多个因子内因素（如被试内因素、刺激内因素）

- 允许缺失值（缺失值多的个体在模型拟合中权重更小）

- 允许连续预测变量

- 提供预测变量作用的强度大小、方向和显著性

- 可以使用广义线性混合模型处理各种类型的因变量

# 固定效应和随机效应

## 固定效应

- 在研究中存在的人群（组）的平均效应

- 更换研究人群或刺激材料，模态（固定效应）对反应时的效应还会再次出现

- 包含了研究者所有感兴趣的水平

## 随机效应

- 因素是从所有样本中抽样的一部分，并不能代表全部感兴趣的水平

- 认为因变量在某个因子（个体或刺激）的不同水平上会有不同（个体水平）

- 认为某些人群或刺激的反应时可能会和平均值有偏移

- 希望解释该因素对因变量作用的变异性

### 随机效应的类型

#### 随机截距

不同被试或刺激 本身的因变量的值会偏离平均值（偏离模型截距的估计值）

#### 随机斜率

固定效应的不同水平对不同被试或刺激的影响程度不同（偏离固定效应的估计值）

### 随机效应的相关性

- 某个因素的随机截距和其他固定效应对该因素的随机斜率之间的相关

- 相关性为1或-1表示模型过拟合

- 相关性可以提供模型变量间关系的更多信息

- 对被试的随机斜率可以反映实验的天花板或地板效应

- 随机效应的相关性的解释需要结合固定效应的正负

### 纳入随机效应的标准

- 一般来说模型要纳入所有可能的随机效应

- 纳入什么随机斜率需要看研究设计

- 随机斜率只能在by-participant或by-item设计中使用，也就是说，固定效应的各个水平在 participant 或 item 中都重复出现了的情况下，才能纳入随机斜率，如果固定效应在participant 或 item 中只出现了一次，那么不可能估计固定效应不同水平对不同的participant或item的影响。

# R语言实现

涉及R包 `lmr4` `afex` 

## 因变量为连续变量

### 单个固定效应

#### 写法

```r
lmer(outcome ~ 1 +predictor + (1 + predictor|participant) + (1 + predictor|item), data = data)
```

- 固定效应写在括号外面，随机效应写在括号里面

- 括号里的竖线称为管道，管道左边的因素 (截距和固定效应) 在管道右边的因素（participant / item）的不同水平上会有变异，以此定义随机截距和随机斜率

- 所有括号外的固定效应都可以写入管道左侧

- 括号外的截距项 1 可以省略，但括号内的不可省略，建议全部写上

#### 模型拟合收敛问题及解决

##### 收敛问题的提示

   * consel警告 model failed to converge / singular converge

##### 解决办法

- 更换 optimizer
  - 使用afex 包的 `all_fit()` 函数确定，然后在 `lmr()` 函数中 使用`control = lmerControl(optimizer = "bobyqa")` 指定
- 强制随机效应相关性为0，降低模型计算复杂度：当随机效应相关不是研究重点时使用
  - 例：强制 participant 的随机截距和斜率之间的相关为0 `t_full.mod <- lmer(RT ~ 1 + modality + (0 + modality|PID) + (1|PID) + (1 + modality|stim), data = rt_data)`
- 增加迭代次数
  - `control = lmerControl(optCtr = list(maxfun = 1e9))`
- 对连续变量中心化或标准化、对分类变量采 sum-coding（各水平之和为0）
- 取消模型收敛后的衍生计算：
  - `control = lmerControl(calc.derivs = FALSE)`
- 减少随机效应（最后的选择）：需要理论合理性

#### 结果检验及解释

##### 固定效应

- 显著性：Likelihood-ratio tests
  - 概念：拟合有某个固定效应以及没有该固定效应的两个模型，计算并比较似然比，以确定该固定效应是否对该模型造成了显著的影响
  - 做法：拟合全模型以及缺少某固定效应的简化模型，其他参数完全一致，并用 `anova()` 函数比较（其实并没有做方差分析，而是似然比检验）`anova(rt_reduced.mod, rt_full.mod)`
  - 简便方式：使用 afex 包中的 mixed() 函数 ，指定 `method = 'LRT'`, 函数检验模型中的所有固定效应和交互作用
  - 1.简洁，2.减少了分析者人为选择其他模型可能造成的偏倚 `mixed(RT ~ 1 +modality + (1 + modality|PID) + (1 + modality|stim), data = rt_data, control = lmerControl(optimizer = "bobyqa"), method = 'LRT')`

      * 报告结果：`Chisq Chi、Df、Pr(>Chisq)`

- 解释：
  - `summary(rt_full.mod)`
  - 看fixed effects 部分
  - ![|450](https://raw.githubusercontent.com/LeiGuo0812/pic_cloud_gl/main/img/20221101232417.png)
  - 主要看estimate部分
  - Intercept表达的是所有其他因子的取值为0时，因变量的取值
  - 固定效应的estimate表达的是其数值上每改变1，因变量的变化量（正负有意义）

##### 随机效应

- ![|425](https://raw.githubusercontent.com/LeiGuo0812/pic_cloud_gl/main/img/20221101232441.png)

- 结果：
  - `Group`：显示了管道右边的因素
  - `Name`：显示了管道左边的随机效应
  - `Std.Dev`.：显示了该效应偏离固定效应和截距的标准差
  - `Corr`：显示随机效应之间的相关性

- 检查随机效应的置信区间
  - `confint(rt_full.mod, parm = "theta_", oldNames = F)`

- 显著性：REML
  - `lmer()`拟合模型时默认使用受限的最大似然估计REML
  - `anova()` 模型比较时默认使用最大似然估计ML
  - 使用`lmer`的默认`REML`方法不适合比较固定效应，因此在用`anova()`比较固定效应时要默认进行`refit`操作，使用ML方法重新拟合模型再比较
  - 但是在比较随机效应时，不能用`anova()`默认的`ML`方法，而是沿用`lmer`的`REML`方法，因此在比较时，不需要重新估计模型，此时要把`refit = FALSE`加上！

- 解释
  - Intercept反映了item和participant在因变量上的固有变异，变异程度为 固定截距 ± 随机截距的标准差，同样，随机斜率反映了 item 和 participant 对固定效应不同水平反应上的变异性，变异程度为 固定效应 ±  随机效应的标准差，随机效应可作为研究的中心，也可以提供额外的信息
    - `coef(rt_full.mod)` 提供了每个 item 和 participant 的随机斜率和随机截距
  - 随机效应的相关性：反映了不同特点的 item 或 participant 对固定效应水平的不同反应之间的相关程度。比如，自身反应比较慢的被试受刺激方式的影响更小（对随机效应相关性的解释需要结合固定效应的符号！因为相关只是数值上的关系！）

      * 随机效应可反映拟合中的问题：当随机效应无法估计时，会使用边界值表示。例如，随机效应的相关结果为 1 / -1，随机效应的方差为0等。

### 多个固定效应

#### 写法

```r
lmer(outcome ~ 1 +predictor1 + predictor2 + (1 + predictor1 + predictor2|participant) + (1 + predictor1+ predictor2|item), data = data)
```

括号内外可添加更多的固定效应和随机斜率，也可以添加交互作用，但模型更难收敛和解释

### 交互作用

#### 注意

- 交互作用的解释依赖于分类变量的编码策略
  - 哑变量编码：截距项解释为所有其他效应为0水平时的因变量值，因此固定效应系数解释为其他效应取值为0时的简单效应
  - sum-coding（总和编码）：此时各个分类变量的所有水平之和为0，截距项解释为所有效应为平均值时的因变量值，固定效应系数解释为其他效应所有水平均值下的主效应
- 交互作用显著时，单个固定效应的系数不再有意义
  - 单个固定效应的系数是在其他效应的取值为0时的效应，但由于交互作用的存在，其他效应不为0时，原固定效应的大小受到交互作用的调制，因此该系数不准确，没有意义。
  - 主效应是因子对截距的调整，而交互作用则是对主效应的调整（当两个效应的取值都不为0时）

#### 写法

- `rt_int.mod <- lmer(RT ~ 1 + modality* SNR + . . ., data = rt_data_interaction)`
- `rt_int.mod <- lmer(RT ~ 1 + modality + SNR + modality:SNR + . . ., data = rt_data_interaction)`

# 错误解决

- the random-effects parameters and the residual variance (or scale parameter) are probably unidentifiable

相关讨论：
[lmer() sometimes doesn't work · Issue #518 · lme4/lme4 · GitHub](https://github.com/lme4/lme4/issues/518)
[Mixed model lab #1](https://bbolker.github.io/morelia_2018/notes/mixedlab.html)

当拟合随机效应模型时，如果每个被试在该随机效应上只有两个测量，则模型的残差随机效应和被试的随机效应就无法分开，导致模型拟合出错。命令 `lmerControl(check.nobs.vs.nlev="ignore")` 可以解决报错，但其方差会在残差随机效应和被试的随机效应间随机分配，导致随机效应拟合不准（固定效应依然准确）。因此，当每个被试只有两个观测时，最好不纳入该随机效应。


# afex 包

使用 afex 包可以方便地指定各种 lmer 和 glmer 的参数，并指定方差分析表中 P 值的估计方法

[GitHub - singmann/afex: Analysis of Factorial EXperiments (R package)](https://github.com/singmann/afex)

当使用一般 LME 时，可以使用 car 包中的 `Anova` 函数，指定方差类型为 3 型，并指定 `method` 参数，即可获得和 JASP 及 SPSS 一致的结果。

当使用 GLME 时，car 包中的 `Anova` 中的方法则无法和 JASP 保持一致，使用 `afex` 包中提供的 method (LRT 和 PB) 即可保持一致。
