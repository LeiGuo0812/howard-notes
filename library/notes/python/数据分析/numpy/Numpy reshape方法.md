#Python #Numpy

1. **NumPy 数组重塑（reshape）**
    - NumPy 的 `reshape` 方法允许改变数组的形状而不改变其数据。
    - 重塑操作需要保证重塑前后数组的总元素数量相同。
    - 可以使用 `-1` 在某个维度上自动计算该维度的大小。
2. **重塑的存储顺序**
    - NumPy 默认使用行优先（C风格）存储顺序，其中多维数组的最后一个轴（维度）的元素在内存中是连续存储的。这种方式下，多维数组的**最后一个轴（维度）的元素变化得最快**。
    - 可以选择列优先（Fortran风格）存储顺序，其中第一个轴的元素在内存中是连续存储的。这种方式下，多维数组的第一个轴（维度）的元素变化得最快。
    - 行优先顺序和列优先顺序在重塑时会影响元素的排列顺序。
3. **一维数组与多维数组**
    - 将一维数组转换为多维数组时，通常关注的是如何将元素“填充”到新的结构中（例如，行优先意味着先填充行）。
    - 在重塑多维数组时，关键是理解元素在内存中的存储顺序（例如，行优先意味着最后一个轴的元素变化得最快）。
4. **三维数组的理解**
    - 三维数组可以视为“数组的数组的数组”，其中第一个维度表示包含了若干个二维数组。
    - 在三维数组中，通常不按照传统的“行、列、层”的几何概念来理解，而是基于数组在内存中的存储方式。
5. **多维数组的转换**
    - 当多维数组转换成另一个多维数组时，元素的排列顺序取决于原数组和目标数组的形状以及存储顺序。
    - 在行优先顺序下进行重塑，元素会按照最后一个轴的顺序进行排列。
