#windows

[固态硬盘装不了系统，可以查到有这个磁盘，也能分区但是boot part是红色的，这是什么问题? - 知乎](https://www.zhihu.com/question/349710070/answer/1333758867)

重装系统时的系统盘需要先激活，如果格式化以后没有激活，会导致 boot part 红色，使用 diskgenius 软件，右键 C 盘，激活该盘即可
