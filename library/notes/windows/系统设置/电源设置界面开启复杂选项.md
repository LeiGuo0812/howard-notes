# 恢复 S3 待机模式

[关于WIN10新版本系统高级电源设置选项缺失问题\_csenabled\_蓝ᝰ离的博客-CSDN博客](https://blog.csdn.net/weixin_56382610/article/details/123996895)

windows 在新版本中，电源高级设置中没有了 USB 设置等选项 （S 3 待机模式），默认是长时间不用 USB 口会自动休眠。在连接脑电进行行为学实验的过程中，如果使用串口打标记，会出现标记出现时间抖动的情况。

查看硬件是否支持 S 3 待机模式
如果有 S 3 存在，说明可以使用该模式
![image.png|400](https://picture-of-howard.oss-cn-shanghai.aliyuncs.com/img/20230320215459.png)

## 使用注册表编辑器方法

1. 打开注册表编辑器
2. 进入地址 `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Power`
3. 新建项命名 `PlatformAoAcOverride`，取值为 0
![image.png](https://picture-of-howard.oss-cn-shanghai.aliyuncs.com/img/20230320220233.png)

## 使用命令行方法
1. 管理员身份运行 cmd
2. 运行 `reg add HKLM\System\CurrentControlSet\Control\Power /v PlatformAoAcOverride /t REG_DWORD /d 0`
3. 重启电脑

```ad-warning
已知问题：在笔记本电脑使用该模式后，连接外接显示器并进入休眠会导致无法唤醒，只能强制关机重启。
```

# 启用 S 0 模式 （Modern Standby）
如果需要关闭 S 3 待机模式，恢复现代待机（Modern Standby）S 0 模式，可以使用下面的方法：

## 使用注册表方法
1. 打开注册表编辑器
2. 进入地址 `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Power`
3. 删除项 `PlatformAoAcOverride`

## 使用命令行方法

1. 管理员身份运行 cmd
2. 运行 `reg delete "HKLM\System\CurrentControlSet\Control\Power" /v PlatformAoAcOverride /f`
3. 重启电脑

**开启 Morden Standby 后，外接显示器后睡眠即可用外接设备唤醒**

# 关于 Morden Standby
