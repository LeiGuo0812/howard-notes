# Freesurfer 7.4.1 安装后 freeview 启动失败问题

- 如果是使用 WSL 安装，请确保已经正确配置图形界面 [[windows/WSL/WSL相关（升级、图形界面、释放空间）|WSL相关（升级、图形界面、释放空间）]]
## GLIBC_2.34 not found
- 启动 freeview 后提示缺少 GLIBC 库

[ubuntu - Error /lib/x86\_64-linux-gnu/libc.so.6: version \`GLIBC\_2.34' not found - Stack Overflow](https://stackoverflow.com/questions/71940179/error-lib-x86-64-linux-gnu-libc-so-6-version-glibc-2-34-not-found)

- 添加库列表：[Ubuntu – 软件包下载地址选集 -- libc6\_2.35-0ubuntu3.6\_amd64.deb](https://packages.ubuntu.com/jammy/amd64/libc6/download)
- 运行 

```
sudo apt update
sudo apt install libc6
```

# FSL 安装
如果官方的 fslInstaller.py 安装脚本无法连接网络，可以选择直接下载（最新到 6.0.4）：

http://fsl.fmrib.ox.ac.uk/fsldownloads/fsl-6.0.4-centos6_64.tar.gz

关于 fsleyes，查看 [FSLeyes - FslWiki](https://fsl.fmrib.ox.ac.uk/fsl/fslwiki/FSLeyes)

fsleyes 从 6.0.2 版本开始由 python 环境提供

6.0.5 以后的版本需要通过 `fslinstaller.py` 安装
[FSL - the FMRIB Software Library](https://fsl.fmrib.ox.ac.uk/fsl/docs/#/)
# AFNI 安装注意事项

- 注意：安装AFNI之前，需要先在Linux中安装R
- 使用 AFNI 官方网站的教程安装后，默认安装在 `home/` 目录下， 可以安装后将文件 (10个) 拷贝到其他位置， 并修改 `~/.bashrc` 中的 `export PATH=$PATH:/<your afni path>/abin`

要拷贝的文件
```
@update.afni.binaries
AFNI_data5
AFNI_data6
AFNI_demos
CD
CD.tgz
abin
afni_handouts
std_meshes
suma_demo
```

之后，将 `home/` 目录下的这些文件删除即可

注意，如果是使用 WSL2， 删除后空间不会释放给 windows，需要手动释放，具体方法参考 [[Linux/环境搭建/WSL相关（升级、图形界面、释放空间）]]
